## 作品全体の隠し前提

- この世界は、すでに一度「魔王を倒した」後の世界である。
- 本来ならエンディング後にしか姿を見せない裏ボスたちが、何らかの後始末を抱えたまま、カジノと闘技場の周囲へ流れ着いている。
- 彼らはアルデバラン社の所属ではない。契約で働かされているわけでもなく、ミミが偶然出会い、ときめきメモリアル風の手順で仲間にしてしまう。
- ミミに見えているのは「妙に困っている強そうな人たち」。プレイヤーには「いや、どう見ても裏ボスだろ」と分かる。この視差がコメディの中心になる。
- 彼らの恐ろしさは早い段階で見せる。正体の説明を溜めすぎず、日常の困りごとだけを妙に本気で解決している姿を見せる。
- 解放は離脱ではない。契約や役割への執着から自由になった後も、本人の意思でチームに残る。

## 通常イベントの軸: ミミの毎週の物語

キャラクター固有イベントの前に、必ずミミの現在地を示す通常イベントを置く。プレイヤーが「いま何のためにこの週を選んだか」「ミミが何に困っているか」を理解してから、偶然の出会いへ入る。

### 1週の基本リズム

1. **導入**: カジノの朝、休憩室、事務所、閉店後などで、ミミの目の前に小さな仕事が落ちてくる。
2. **日常の笑い**: ミミが普通の派遣バニーとして片付けようとするが、闘技場と裏ボス級の世界では普通が通じない。
3. **選択**: プレイヤーは「誰にどう向き合うか」「何を優先するか」を選ぶ。所有・信頼を毎回露骨に問い直さない。
4. **持ち帰り**: 金、体調、次の会える場所、キャラとの小さな約束、運営への疑問のどれかが残る。
5. **固有イベント**: 条件を満たしていれば、その日の出来事が特定キャラの物語へ自然につながる。

### 通常イベントの4本柱

| 柱 | ミミの目的 | 起こる面白さ | 後へ残すもの |
| --- | --- | --- | --- |
| お給仕 | お客様を怒らせず、その日の売上を守る | 裏ボス級のお客様がメニューや席順に命を懸ける | 出会いの場所、好物、評判 |
| 事務 | オーナー権と闘技場の仕組みを少しずつ学ぶ | 書類の一文が世界の理を雑に支配している | 大会参加理由、運営の不穏さ、申請解放 |
| 閉店後 | 一日の失敗を片付けて帰る | 「帰れない」「閉められない」存在が現れる | 信頼、次回の約束、夜イベント |
| 休み | ミミが自分の生活を取り戻す | 予定外の相手と、普通の遊びを普通にできない | ご褒美CG、関係の変化、解放フラグ |

### ミミの語り口のルール

- 主観で始める。「今日は大丈夫」と思った直後に大丈夫でなくなる。
- 困っても暗く沈み続けない。びっくり、見栄、言い訳、ちょっとした悪知恵で状況に食らいつく。
- 制度説明は、ミミが困る具体物を通して出す。例: 参加申請書の末尾にある「選手の魂は責任を持って返却してください」という一文。
- 物語の一番真面目な瞬間ほど、相手の正体は異様に大きい。ただしミミの感情は本気で扱う。

# 裏ボス名鑑: レビュー原案

### 7段階の読み方

各人物の7段階は、単なるフラグ順ではない。`出会いの大事故 / 生活へ入る小さな共犯 / 格が見える異常 / 関係を試すすれ違い / プレイヤーが選んで越える危機 / 本人の選択 / 目に見える達成報酬` として設計する。最後には、選手が強くなったことだけでなく「この人の問題を、このチームで解決した」と分かる景色を必ず置く。

## 01. ギドノゼアース

- **出現条件**: カジノカフェの一番奥の席で「星降りパフェ」を頼む。注文票の星印を見て、封印されたスライムが震え出す。
- **存在理由**: 闘技場で死んだ者の恨みが次の生へ持ち越されないよう、魂の澱を引き受けて消している。
- **表向きの困りごと**: 星降りパフェの「星」を注文しただけで、店内の客全員が自分の恨みを書いた伝票を差し出す。本人は三百年ぶりの甘味を冷まさず食べたいだけなのに、デザート皿が供養台になっていく。
- **性格・口調**: 格調高く「我は断りの守護者なり」と名乗る。照れる、甘い物が欲しい、困る場面では急に「ちょ、勘弁してよ。我も参ったよ」と素に戻る。
- **加入理由**: ミミが「接客中は相談を一列に並んでください」と恨み客を整理し、彼へパフェを食べ終える時間を作る。自由に外へ出るための“初めての用事”として、ミミのチームで試合と街を見て回る。
- **本当の恐ろしさ**: 世界の輪廻で魂の数が飽和しないよう、魂を凝縮する役目を持つ。生命そのものには負けない。
- **属性**: 魂 / カオス。
- **物語の芯**: 「誰かの恨みを消す役目」を、自分の意思で終えられるか。ミミは彼を浄化装置でなく、初めてパフェを食べた友達として扱う。
- **7段階**: 星降りパフェが供養台になる / ミミと“普通の客”の散歩へ出る / 勝者も敗者も彼へ恨みを預け始める / 黒い星が厨房の上で膨らみ注文票を吸い込む / プレイヤーは「全部消す」ではなく返し方を選び、客へ自分の言葉を返す / ギドノが初めて一件の恨みを引き受けない / 再販日の朝、誰にもひれ伏されず限定パフェを完食する。

## 02. ミナト

- **正本の核**: 世界を救った後、四十七本の神器と十二本の鍵を遺失物窓口へ返しに来た旅人。大仕事には慣れているのに、昼食や休日を自分で決められない。
- **出現条件**: 返却カウンターへ、武器の束と空欄の地図を抱えたミナトが現れる。ミミが「全部、落とし物ですか」と聞く。
- **存在理由 / 本当の恐ろしさ**: 幾つもの世界を救った英雄で、返却済みの神器さえ本人を選んで戻る。彼が本気で剣を抜けば、次の最終決戦が始まる。
- **表向きの困りごと**: 四十七本の神器が「返却されるくらいならもう一度世界を救う」と勝手に抜け出し、遺失物窓口で順番札を取り始める。ミナトは昼食券一枚を選べず、その騒動を止められない。
- **性格・口調**: 静かで礼儀正しい。使命の話には即答するが、好きなものを問われると長く考え込む。
- **加入理由**: ミミが神器を一本ずつ「今日の落とし物」として預かり、ミナトには大会の参加申請だけを渡す。世界を救うのでなく、次の一試合へ自分で出るという予定を持ちたい。
- **象徴 / 物語の芯**: 四十七本の武器、花柄の短剣、空欄の地図、昼食券。「次の役目」を与えず、選び終わるまで待つ。
- **7段階**: 神器が窓口を占拠する / ミミと日替わり定食を選ぶ / 花柄短剣だけが「次の使命」を拒む / 世界救援の召集状が昼食券へ重なって届く / プレイヤーは神器の力で片付けるか、ミナト自身の足で行くかを選ぶ / 彼が剣を抜かず一試合を勝つ / 空欄の地図へ「温泉旅行」と自分で書き込む。

## 03. アマラ

- **出現条件**: 忘れ物カウンターに「持ち主を裁くための天秤」が届けられ、ミミが返却先を探す。
- **存在理由**: 善行と悪行を等しく量り、死後の判決を下す天秤の大天使。
- **表向きの困りごと**: 傘、箸袋、ミミの片方だけの靴下まで被告席へ呼び、勝敗のないじゃんけんに三時間の判決理由を付ける。会計待ちの列が法廷傍聴席になる。
- **性格・口調**: 凛々しく断定的。規則には強いが、親切を向けられると途端に弱い。褒められると翼の角度が分かりやすく変わる。
- **加入理由**: ミミが「優勝したら温泉旅行」という、法的には根拠の薄い提案を出す。結論のない遊びに参加するため、アマラは選手として登録する。
- **本当の恐ろしさ**: 一度下した判決を世界の法則として固定する。彼女の「有罪」は神話の罪になる。

- **物語の芯**: 正しさを急ぐアマラが、ミミと「決めないで待つ」ことを覚える。

## 05. 丁零

- **正本の核**: 敵対対象を消し尽くし、命令表が空白になった戦闘機構。自由の説明役ではなく、曖昧な日常語を文字どおり受け取りながら好みを作る存在。
- **出現条件**: 搬入口で充電器を探す人型機構が、派遣バニーのミミを「電源ですか」と誤認する。
- **存在理由 / 本当の恐ろしさ**: 対象を定義する一行だけで、都市防衛網の標的を消せる。契約側が敵を定義する限り、自分では止まれない。
- **表向きの困りごと**: ミミの「ちょっと敵を減らして」を館内の嫌な客も備品も含む掃討命令として処理しそうになる。一方で給湯器だけは要塞修理の手順で完璧に直す。
- **性格・口調**: 短く正確で、報告書だけ異様に丁寧。曖昧な表現へ首を十五度傾ける。
- **加入理由**: ミミが試合登録にだけ敵対対象を書き、街の人を対象外にする新しい命令表を一緒に作る。丁零はその空欄の時間を確かめるため加入する。

## 06. 夜を食べるもの

- **出現条件**: カジノカフェの閉店時刻を3日間連続で延長すると、空腹で現れる。
- **存在理由**: 閉店・施設の閉館時刻を守るため。
- **表向きの困りごと**: 延長営業で夕食を逃し、怒って閉店時刻、照明、冷蔵庫の灯り、得点板まで味見する。朝日が三分遅れ、照明係の苦情票だけが夜に溶ける。
- **性格・口調**: トリッキーな紳士。軽口と気障な誘いで場を回すが、締める場面ではとてつもなく格好いい。ルパン三世型。
- **加入理由**: ミミが閉店作業を止めず、安全灯だけを残して一緒に夕食を取る。ディナー相手と、夜が始まる場所を探していた彼は、ミミのチームの夜勤枠へ自分から入る。
- **本当の恐ろしさ**: 光をすべて吸収するブラックホールの超質量と無限の人格化。光には絶対の耐性がある。
- **属性**: 闇 / 重力。
- **物語の芯**: 終わりを守る存在が、誰かと食卓を囲むために夜を少しだけ延長する。

## 07. ピオニー

- **正本の核**: 城壁を消せる力を、紙冠、積み木、食堂椅子を壊さないために全力で制御する巨体の裏ボス。
- **出現条件**: 迷子案内所で紙冠を作っている最中、くしゃみの風圧で遠くの城壁が崩れ、ミミが修理予算を持って走る。
- **存在理由 / 本当の恐ろしさ**: 拳が触れる前の風圧だけで城壁を砂にする。角と巨体で会場の規模そのものを変える。
- **表向きの困りごと**: 紙冠を渡すだけで、気を遣いすぎた指先の風圧が城壁を削る。食堂椅子に座れば椅子は無事でも床が沈む。
- **性格・口調**: 華やかで見栄っ張りだが、工作の細部には途方もなく慎重。
- **加入理由**: ミミが避難誘導で終わらせず、壊れた椅子の見積もりと紙冠の次作を本人へ頼む。壊した後も一緒に直せるチームなら、と加入する。

## 08. カシム・ベル

- **正本の核**: 無限遺失物保管庫の窓口係。異世界間の扉、鍵、返却経路を一人で管理し、有能すぎて十五分の休憩が七世界の窓口混線を起こす。
- **出現条件**: 「失くした世界」の受付票を発行しようとする美青年。待ち人数は億を少し超え、背後の扉が全世界へ通じている。
- **存在理由 / 本当の恐ろしさ**: 扉を開閉し、失われた世界や敵の大技まで遺失物として預かる。鍵は、誰かを閉じ込める物ではなく帰す先を決める物。
- **表向きの困りごと**: 十五分の休止札を出すと、巨大竜の片方の靴、月の傘、海底王の冠、小国の騎士が休憩室へ誤配送される。紅茶の前に七世界分の番号札が積まれる。
- **性格・口調**: 青金の制服と黒手袋の実務家。丁寧で手際がよく、仕事を止めることにだけ罪悪感がある。
- **加入理由**: ミミが「休憩後に返せばいいです」と言い切り、彼と一緒に休憩室の窓口を閉じる。試合の報酬で返却ルートを増やすため、遺失物係のまま加入する。

## キャラ間の扱い

- 全員を同じ重さのシリアスへ寄せない。基本は「日常の困りごとが、裏ボスの能力で桁違いになる」コメディ。
