# ミミのときめき裏ボス闘技場

明るい週刊育成シミュレーションと、監督型3対3オートバトルを組み合わせた
ブラウザゲームです。1周26週、初回75〜90分を想定しています。

## 起動

```powershell
npm install
npm run dev
```

本番ビルドと自動監査:

```powershell
npm test
npm run build
```

## 実装範囲

- 26週の周回進行と毎週必ず発生するイベント
- 固定導入、15人の選手、個別の遭遇・成長・危機・解放・後日談
- 15人の固有ポートレート、固有の遭遇二択と契約危機二択
- 行動ごとの効果予告、人物イベント候補数、注目選手による緩い進行補正
- 選択直後の結果文と信頼・所有・資金・育成Pの差分表示
- 固有育成ポイントと共有育成ポイント
- 3人編成、装備購入、試合への賭け
- 3対3オートバトル、試合方針、敵の気配を読む3種類の監督指示
- 通常、追加査定試合のある支配、専用珍事件が起きる混線の段階解放ルート
- 解放コレクション、説明スキップ、殿堂入りチームの永続保存
- デスクトップとモバイルのレスポンシブUI
