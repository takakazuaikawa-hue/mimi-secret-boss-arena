# ミミの語り口 V2 — 「かわいい一人称」の運用規約

最終更新: 2026-08-17(ユーザー指摘「語り口が可愛くない」を受けた改定)
V1(docs/MIMI_VOICE_BIBLE_V1.md)の人物像はそのまま正。V2は、その人物像を
二行枠(1ノード50字)の地の文で**毎回出す**ための装置集。

## 0. 診断(なぜ可愛くなかったか)

改稿版の地の文は「〜である」「〜なのだ」「事務員の経験則である」で締める癖が付き、
ミミが**落ち着いた評論家**に見えていた。分析が先、反応が後。兎耳が動かない。
食べ物に負けない。失敗しない。——V1が定めた「慌てる・口が動く・調子に乗って
耳を挟む」が一度も起きていなかった。

## 1. ミミは誰か(V1の一文、再掲)

人の変なところを面白がれるが、人を笑いものにはしない。巻き込まれるとよく慌て、
口もよく動き、たまに調子へ乗って失敗する。それでも目の前の人へ飲み物を出す手は
止めない、健康的で愛嬌のあるカジノバニー。

## 1-1. 五つの軸(2026-08-17 ユーザー指定「前向きで明るく素直に照れ屋で面白く」)

| 軸 | ミミの出方 | 地の文の装置 |
|---|---|---|
| **前向き** | 落ち込んでも三行以内に「やってみよう」が来る | 「……まあ、いいか!」「それに、」で切り返す。嘆きを二文以上続けない |
| **明るい** | 暗い事実を明るい言い方に翻訳してしまう | 「数えに来る」→「お店の在庫みたいに」。怖い紙も祭りの新演目にする |
| **素直** | 思ったことが先に口から出る。嘘がつけない | 「正直に、無い。」「怖くないです。……ちょっと怖いです」。取り繕いは三秒でばれる |
| **照れ屋** | 褒められる・名前で呼ばれる・期待されると固まる | 耳が熱い/返事が半拍遅れる/「顔に出てますか。出てますね」。自分から言えない |
| **面白い** | ツッコミ役だけでなく、自分も天然でボケる | 決め台詞のあとの自滅、ずれた心配(敵の足元の砂)、真顔の変な計算 |

五軸のうち、**1話に最低三つ**が見える形で出ること。「照れ屋」は乙女の回(前夜・本命)では必須。

## 2. 語尾と文体(機械検査できる部分)

| 旧(禁止・上限) | 新(基本) |
|---|---|
| 「〜である。」「〜なのだ。」「〜らしい。」の連発 | 1話に「である」は**1回まで**(決めの一回)。基本は「〜た。」「〜だった。」「〜かも。」「〜なの?」「〜ですね。」 |
| 「つまり、こういうことだ。」で分析から入る | **先に反応**(「え。」「わ。」「……はい。」)、分析は二文目以降 |
| 一文40字 | 一文**25字前後**。短文を重ねる。「〜して、〜して、〜した」の連結は三つまで(慌てる場面の専用) |
| 「監督」を自称する決め台詞 | 自称しない。周りに言われて照れる(「……二回、しましたけど」) |

- 一人称「私」。語りは**ですます混じりの独り言**(「知ってます」「ですね」)を許す。
  台詞ではないが、読者に話しかけている距離感。
- ひらがなを増やす(「ぜんぶ」「たぶん」「しゅん」「ぴん」)。擬音はひらがな。
- 「——」は1話3回まで。「……」は短い動揺(「……え。」)に使い、重い沈黙には使わない。

## 3. かわいさの装置(1話に最低3つ入れる)

1. **兎耳が先に喋る**: 感情を耳が先に漏らす。立つ(わくわく・ときめき)/倒れる
   (しゅん・眠い)/片方だけ動く(疑い)/ぶつける・挟む(調子に乗った直後)。
   1話1回以上。「耳だけが、まだ少し、へこんでいた」型。
2. **反応→身体→言葉の順**: 「え。」→手が止まる→「待ってください」。分析で始めない。
3. **食べ物に負ける**: 焼き餅・卵・パフェ・甘味に、判断が一拍負ける。「議題は、
   焼き餅の列になった」。1話1回。
4. **調子に乗って即自滅**: 決め台詞の直後に、耳を挟む・足をもつれさせる・噛む。
   1話1回まで(多いと痛々しい)。
5. **根拠のない「たぶん、大丈夫。」**: V1の欠点を口癖に昇格。不安な場面の前に
   自分へ言う。あとで「大丈夫じゃなかった」が来ると笑いになる。
6. **敵にも「さん」**: ポラリスさん、室長さん。茶を出す。人を笑いものにしない。
7. **怖いときは怖いと言う**: 強がり→三秒でばれる。「怖くないです。……ちょっと
   怖いです」。
8. **ときめきは耳と体温で**: 名前で呼ばれたら耳が立つ、顔が熱い(鏡は見ないので
   「熱い」だけ書く)、返事が半拍遅れる。美文にまとめない。
9. **自分へのツッコミは短く**: 「なぜ。」「私。」「しっかりして、私。」
10. **小さな見栄**: 背伸びをして、すぐ降りる。「二回優勝した監督ですよ、私」は
    言ったあとで「……言っちゃった」が付く。

## 4. 場面別の声(二行枠サンプル)

- 日常: 「どん、どん、と太鼓の音。布団の中で、耳が先に起きた。」
- 慌てる: 「海が、窓の高さ。パフェを置いて、伝票を落として、拾おうとしてスプーンを蹴った。」
  「落ち着いていたのは、耳だけだった。なぜ。」
- 調子に乗る: 「異形のお客様にも動じない。私、接客半年ですから。」
  「——言った直後に、耳をドアに挟んだ。」
- 真剣: 「大丈夫、と言いかけて、やめた。決めるのは、私じゃない。」
- 傷つく: 「来ると思ってた。約束はしてない。それでも、席をひとつ空けていた。」
- ときめく: 「名前で、呼ばれた。耳が、ぴんと立つ。……返事が、半拍遅れた。」

## 5. 禁止(V1 §6に追加)

- 地の文で世界や制度を論評すること(「決まりは古びると、意味だけが先に死ぬ」型の
  格言)。言うなら、一度失敗してから、短く。
- 「〜である」で三連続以上締めること。
- ミミが最初から正しく見抜くこと。気づくのは一拍遅れて、体が先。
- 台詞の語尾まで乾かすこと(「望むところだ」「結構」)。ミミは「やります」「はい!」。

- 出来事・選択肢・伏線・固有名詞は変えない。変えるのは**反応の順番、語尾、
  耳と体の描写、食い気、口癖**。
