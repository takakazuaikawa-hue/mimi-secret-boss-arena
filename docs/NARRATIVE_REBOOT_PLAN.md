## 1. 診断（現行本文の計測値）

対象: `src/narrative/content/` 全107ブロック、1,976行。

| 問題 | 計測値 | 影響 |
| --- | --- | --- |
| 遭遇場面の定型文使い回し | 15人中12人が一字一句同じ導入文 | 「それぞれの物語」が最初の一文で死ぬ |
| 地の文独白への偏り | 全行の71%が思考モノローグ、会話は29% | 事件が起きず、感情の要約を読まされる |
| 選択肢の物語分岐 | 92箇所すべて同一行へ合流 | 選択が数値差分と結果一文だけになる |
| 基準書との乖離 | VOICE_BIBLEの三拍(見る→反応→ずらす)が本文に不在 | 語り口が湿った文学調に固定される |
| コメディ配分の不履行 | MASTER_PLANは15人中12〜13人コメディ主調と規定。実際の遭遇はほぼ全員が静かな感傷調 | 「規模の落差」の笑いが発生しない |

補足: 基準書([MIMI_VOICE_BIBLE_V1.md](MIMI_VOICE_BIBLE_V1.md)、
[NARRATIVE_MASTER_PLAN.md](NARRATIVE_MASTER_PLAN.md)第2章)自体は優秀。
問題は本文が基準を実行していないこと。良い骨も既にある
(アマラの箸袋モチーフ、夜を食べるもの・ギドノの導入は固有文)。

## 2. リサーチからの採用原則

1. **相手の反応が感情を曲げる**(GS3プレイヤー分析): プレイヤーの心を動かすのは
   地の文の詩情ではなく、相手キャラの強い反応(拒否・宣告・要求・誤解)。
   毎場面、裏ボスがミミへ「何かを要求する/宣告する/巻き込む」こと。
2. **意味のある選択の三条件**(VN設計論): 主人公の価値観が出る / 本気の
   ジレンマである / 選んだ先の手触りが違う。「明らかな正解」は選択ではない。
3. **フォールドバック設計**: 無限分岐は不要。選択→固有の結果描写→記憶フラグ→
   後の場面での呼び戻し(コールバック)で「選んだ実感」を作る。本作のスキーマは
   `setFlag`/`schedule`/`when`で既にこれを実装できる。
4. **場面=事件**(脚本術の基本): 各場面に「目的→障害→転換→次への引き」を必ず
   置く。気配や余韻だけの場面を作らない。

## 3. 改稿基準（全ブロック共通）

### テイスト指定（2026-08-09 ユーザー承認）

**高橋留美子イメージ、ただし現代的**。具体的には:

- **同居型ドタバタ**: 非常識な存在と異常事態が日常業務へ当然の顔で同居し、
  登場人物はそれを実務的に受け入れて進める。驚くのは一拍だけ、あとは対処する。
- **全員が自分勝手に真剣**: 誰も冗談を言わない。各自が自分の目的へ全力で、
  その衝突だけが可笑しい(MASTER_PLANの「真剣さの衝突」と同一)。
- **反復ギャグ**: 人物ごとに固有のお約束(アマラ=何でも開廷する、等)を決め、
  場面をまたいで形を変えながら繰り返す。
- **照れ隠しとすれ違い**: 感情は素直に言わせない。意地、誤読、業務用語への
  逃避で進め、決定的な一言は最小の文字数で刺す。
- **感傷は短く**: しんみりは最大2行で切り、笑いか実務へ戻す。余韻の引き延ばし禁止。
- **現代的であること**: 派遣、シフト、ポイントカード等の現代語彙とテンポを保つ。
  暴力ツッコミ・古い性役割・昭和的な間は使わない。

### 文体指定（2026-08-09 ユーザー追加指示）

**高校生が夢中で読めるライトノベル風**。旧本文の「何を言いたいのか分からない
散文」を全廃する。

- 一文を短くする。一行につき意味は一つ。
- 地の文はミミのツッコミ思考を中心にする(「判例。休憩の判例って何。」型)。
- 抽象名詞のもたれ合い(「孤独が場所を取っていた」型)は禁止。
- 読者が三秒で画を思い浮かべられない文は書き直す。
- 会話はテンポ優先。往復で笑いを作り、説明台詞は禁止。

### 語り口

- ミミの地の文は VOICE_BIBLE の三拍を厳守: **具体的に見る→素直に反応する→
  少しずらして言う**。抽象的な心情要約(「孤独が場所を取っていた」型)は禁止。
- 会話比率を全ブロックで**55%以上**にする。裏ボスは自分の場面で最低8回話す。
- 導入文は15人全員固有。**その人物の世界法則が既に暴走している現場**へミミが
  途中から入る(in medias res)。定型文は全廃。

### 事件性

- 各場面の必須構造: ①ミミの小さな目的 → ②人物固有の異常事態が目的を妨害 →
  ③エスカレーション(最低2段) → ④転換(相手の意外な一面が見える) →
  ⑤次に会う理由が残る。
- 笑いは MASTER_PLAN 第2章の5種(規模の落差・真剣さの衝突・実務感覚・
  演出過剰・固有世界法則)から毎場面2種以上を使う。

### 人物の核心とうねり

- 15人全員に一行の「背骨」を定義する:
  **欲しいもの / 誤った信念 / 7場面で崩れる瞬間 / 支払う代償**。
- 各場面はこの背骨の異なる面を見せる。meet=法則の提示、join=法則にミミが
  巻き込まれる、bond=法則の楽しい共犯、power=法則の代償の予感、
  crisis=誤った信念の破裂、liberation=信念の選び直し、epilogue=法則の再発明。
- 具体物のモチーフを meet で植え、最低3場面で再登場させる(アマラの箸袋方式)。

### 選択肢

- 二択は「価値観の分かれ道」にする(安全/踏み込む、実務/感情、など)。
- `result` は最低3文の固有描写にし、選ばなかった側と明確に違う手触りを持たせる。
- 選択は `setFlag` で記憶し、後続場面の台詞1箇所以上で呼び戻す
  (エンジン変更なしで実装可能)。

## 5. パイロット改稿: アマラ遭遇場面 v2 台本案

方針: 「宇宙規模の法廷」対「名札再発行の書類一枚」の規模の落差。
アマラは威厳を保ったまま、状況だけが可笑しくなる。箸袋モチーフは維持。

  はずだった。相談室の扉を開けるまでは。

ミミ(思考): 長机が三つ、法壇の形に積んである。椅子が二列。窓際の観葉植物には
  「傍聴席」の札。私の申請書を受け取るはずの窓口は、「被告席」になっていた。

アマラ: 「開廷します。本日の被告、従業員休憩規定・第八条」

ミミ: 「あの、名札の再発行を……」

アマラ: 「証人ミミ。あなたは先週火曜、休憩十五分のうち十一分を、泣いている
  お客様の付き添いに使った。相違ありませんか」

ミミ: 「な、なんで知って……相違ないです」

アマラ: 「規定第八条は、その四分の返還を定めていない。つまりこの規則は、
  休ませないために書かれています」

[効果: flash / 一枚絵: アマラ]

ミミ(思考): 白い手袋が規則集の余白を指す。赤字がびっしり。全部、誰かの
  取り戻せなかった数分の記録だった。怖い人だ、と思った。思ったのに、
  先に出た言葉は接客用だった。

ミミ: 「……お茶、淹れ直しましょうか。それ、冷めてますよね」

アマラ: 「今は審理中——」

ミミ: 「証人からの差し入れです。却下できます?」

ミミ: 「弁護人は、いないんですか」

アマラ: 「……この闘技場に、規則に負けた側へ立つ者はいません。私を含めて」

ミミ(思考): 「私を含めて」。その五文字だけ、判決の声じゃなかった。

[選択肢]

  → result: 申請書は「証拠物件ホ」として受理された。名札は三日後、
    「本法廷はあなたの名前を正しく表示する権利を認める」という判決文つきで
    届いた。判決文の隅に、小さく手書きの「またどうぞ」があった。
  → flag: amara.meet.left / 効果なし(再会は後の週の固有イベント)
