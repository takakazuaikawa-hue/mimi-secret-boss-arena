# ビジュアル資産ショットリスト

最終更新: 2026-07-31

## 1. 目的

脚本、人物設定、画面上の役割が確定した画像だけを生成する。画像枚数ではなく、
物語の理解、感情の山、人物への愛着、画面操作を強めたかで採否を決める。

## 2. 資産間の関係

```text
人物基準画像
  -> 全身立ち絵
    -> 表情差分
      -> 一枚絵
        -> サムネイル・ギャラリー

場面脚本
  -> 背景
  -> 登場人物と表情
  -> 一枚絵を出す正確な行
  -> クリック送り後の画面復帰
```

一枚絵は人物基準画像と確定脚本の両方へ従う。背景や一枚絵を理由に本文を曲げない。

## 3. 共通品質基準

- ゲーム内一枚絵は横長。最終実装寸法は既存資産に合わせて1672x940前後。
- 重要人物の顔、髪、耳・角、衣装、装飾、体格を基準画像と一致させる。
- 手指、腕、衣装の接続、持ち物との接触を原寸で確認する。
- 画面へ文字を焼き込まない。固有名、説明、登録結果はUI側で表示する。
- 暗いホラー調へ寄せず、明るい乙女ゲームの光と清潔感を保つ。
- 生成結果は新しい版名で保存し、採用判定前に既存資産を上書きしない。
- 動的に変わるチーム構成を、固定一枚絵で事実のように描かない。

### 飽きを防ぐ人物ルートCG設計

全人物へ同じ「出会いの驚き、日常の二人、最後に見つめ合う」を機械的に配らない。
各人物のCG構成は、次の軸のうち最低三つを前の人物から変える。

- 感情報酬: 信頼、笑い、達成、畏怖、安堵、共犯、再会、逆転、祝祭。
- ミミの立場: 待つ、教わる、助けられる、負ける、巻き込まれる、並んで作る。
- 距離: 遠景の圧倒、群像、対面、背中合わせ、物越し、同じ景色を見る。
- 時間と光: 朝、昼、夕暮れ、夜、雨、試合照明、祭り、室内の静けさ。
- 視覚の主役: 顔、異形の全身、小道具、景色、作業、勝敗の瞬間、空いた席。

読了ご褒美CGは必須候補だが、必ずしも恋愛的な接近や視線の交換にしない。
「その人物とここまで進んだからだけ見られる状況」を報酬にする。相棒、家族、友情、
仕事仲間などの関係を、同じ恋愛構図へ押し込まない。

連続する二人物で禁止する反復:

- 同じ朝の逆光で二人が地図や書類を持つ。
- ミミが左、相手が右で正面から見つめ合うだけの構図。
- 小道具の印や名前を見つけて胸が跳ねる結末。
- 契約解除書類を中央に置くクライマックス。
- すべての山場を顔の近い二人絵だけで処理する。

ミナトの読了報酬は「未来の予定へ含まれる静かな再会」。次の人物では、同じ報酬、
朝の地図、対面二人構図を使わない。

監査結果:
- v2は不採用。券の下の三指が団子状に連結し、五指と関節を明瞭に判別できない。
- v3は生成途中で中断された候補で、最終監査を通っていないため不採用。
- v2、v3ともゲームへ未接続。現行画像の参照は変更していない。
- 次回は手だけの再編集を一回実行し、拡大監査に失敗した場合は画像全体の再生成を
  続けず、元画像を人物レイヤーと背景へ分ける制作方法を検討する。
