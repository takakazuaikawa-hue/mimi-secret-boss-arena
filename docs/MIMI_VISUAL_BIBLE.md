# ミミ視覚正本

## 正式参照

新しい一枚絵でミミを描く場合、次の二枚を必須参照にする。

- `/assets/ui/title-key-visual.png`
- `/assets/ui/weekly-hub/work.webp`

文章だけでミミの容姿を指定して生成してはならない。人物CGと正式参照を同時に
画像生成へ渡し、採用前に髪、耳、リボン、上着、胴衣、配色を照合する。

## 変えない識別核

- 成人女性として一貫した顔立ち、年齢感、体格。
- 琥珀から明るい茶色の大きな瞳。
- 栗色の髪。結び方や長さを変えても色、前髪、顔まわりの印象を保つ。
- 根元と外側が黒く、内側に暖色がある長い兎耳。普通の茶色い獣耳へ変えない。
- 明るく健康的で、表情と兎耳の動きが大きい。

標準衣装は、大きな赤いリボン、赤い燕尾ジャケット、黒と金のコルセット風衣装、
白い胸元、黒い蝶ネクタイで構成する。これは識別の基準であり、全場面へ同じ服を
強制するものではない。

## アレンジ可能な要素

衣装と髪型は、季節、仕事、場所、感情、行動に合わせて積極的に変えてよい。
ポニーテール、まとめ髪、編み込み、短く見える結い方、外套、白い業務制服、
エプロン、胴長、安全帯、温泉着、式典服などを許可する。

ただし、画像ごとに生成前に次を短く記録する。

- 変更理由。
- 標準から変える髪型と衣装。
- 変えずに残す識別核。
- 同じ場面にある前後画像との連続性。

髪型と衣装を同時に大きく変える場合は、顔、瞳、髪色、兎耳を強く維持し、赤い
リボン、黒金の装飾、名札など標準衣装から一つ以上の橋渡し要素を残す。

## 採用前チェック

1. 正式参照と同じ人物に一目で見えるか。
2. 顔、瞳、髪色、兎耳、年齢感の識別核が一致するか。
3. 手指、耳、髪、衣装の構造が破綻していないか。
4. 本文中の小道具の数と位置が一致するか。
5. 不合格画像を正式JSONへ接続していないか。
