# 画面・機能役割マトリクス

最終更新: 2026-07-28

## 分類

- **CORE**: ノベル体験そのもの。最初の縦切りで完成品質が必要。
- **SUPPORT**: 読解、選択、育成を支える。ライト層向けの親切さを優先する。
- **LATER**: 本編満足後の再訪価値。縦切り完成後に作る。
- **REDUCE**: 情報過多、重複、古い仕様。削減または統合する。

| 画面・機能 | 分類 | ノベル体験での役割 | 改修順 |
| --- | --- | --- | ---: |
| タイトル | CORE | 一目で明るさ、異常な仲間、作品の格を約束する | 縦切り時に最終確認 |
| プロローグ | CORE | ミミを好きにさせ、最初の異常へ最短で運ぶ | 1 |
| テキスト・選択画面 | CORE | 読む、笑う、迷う、結果を受け取る中心 | 1 |
| 立ち絵・一枚絵表示 | CORE | 人物の格、距離、感情の変化を伝える | 1 |
| 第1週ギドノイベント | CORE | 本作でしかない体験を証明する | 1 |
| 週行動ホーム | CORE | 次に読みたい物語を選ぶ | 2 |
| イベント結果 | CORE | 選択が何を変え、何が続くか示す | 2 |
| 初公式戦 | CORE | 人物と選択を動的な山場として回収する | 3 |
| 戦闘テキスト送り | CORE | 選手の行動をプレイヤーの速度で見届ける | 3 |
| 人物詳細 | SUPPORT | 好きになった人物をもっと知る | 2 |
| 育成 | SUPPORT | 愛着を強さへ変える。推奨と自動配分を持つ | 3 |
| 編成・装備 | SUPPORT | 次の試合の簡単な作戦を作る | 3 |
| 試合準備 | SUPPORT | 相性と推奨を平易な言葉で知らせる | 3 |
| タイムライン | SUPPORT | 物語の現在地と次の山場を予感させる | 2 |
| 契約・所有数値表示 | REDUCE | 現行演出を内部状態として補助する | 常時表示を廃止候補 |
| 詳細能力値 | SUPPORT | 興味のある人が開く第二階層 | 初期画面から後退 |
| ローディング | SUPPORT | 世界観を保ち、待ち時間を不安にしない | 縦切りQA |
| エンディング | CORE | 選択と人物の感情をクリック送りで回収する | 全編制作 |
| 記録室・ギャラリー | LATER | 好きな場面を再訪し、人へ見せる | 本編後 |
| 殿堂フリー対戦 | LATER | 育てたチームを残す | 戦闘完成後 |
| 過去チーム大会 | LATER | 周回を越えた遊びを作る | 最終工程 |
| 旧タイトル実装 | REDUCE | 現行体験へ寄与しない死んだコード | 基盤分割時に削除 |
| 重複CSSガード | REDUCE | 見た目の不安定要因 | 画面移行時に除去 |

## 縦切りのナビゲーション

縦切りでは、次の一本道を完全に検証する。

`タイトル → 短い導入 → 第1週選択 → ギドノとの出会い → 選択結果 → 人物詳細 →
第2・3週の仲間集め → 推奨育成・編成 → 初公式戦 → 戦後人物場面 → セーブ`

この経路に不要な高度機能は隠すか後段へ置き、説明だけの画面を挟まない。
