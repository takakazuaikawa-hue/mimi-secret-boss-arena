# 全人物・報酬CG横断監査

## 採点基準

各20点、合計100点。90点以上を採用水準とする。

1. 人物固有性: 名前を隠しても、その人物にしか成立しない場面か。
2. 主役性: 人物が画面の焦点で、最高に格好よく、小粋で魅力的か。
3. 決断の可視化: 能力紹介ではなく、物語上の選択が一目で読めるか。
4. ミミの当事者性: ミミが見物人ではなく、その決断を生んだ相手として画面にいるか。
5. コメディとの両立: 可笑しさを残しつつ、クライマックスの格を壊していないか。

全身・半身を問わず、左右の肩から肘、手首、親指まで線を追い、右手と左手の向き、腕の本数、五指を別項目として確認する。見た目の完成度が高くても、左右手を説明できない画像は不採用とする。

## 制作順

1. ギドノゼアース、夜を食べるもの、うしろ、十七号室: 異形性と本作固有の第一印象を優先する。
2. ミナト、アマラ、カシム・ベル: 静的な会話絵を人物固有の決断へ置き換える。
3. さざなみ、マリアン: 既存の楽しい日常絵を残し、別の人物報酬CGを追加する。
4. シャハル、テイレイ、ピオニー、ヴォルフ・ナイン: 暫定合格を本文・手指・ミミの一貫性まで再監査する。

状況CGは削除しない。世界と事件を理解する絵として前半へ残し、人物報酬CGを決着直後へ追加する。

## 横断監査結果

2026-08-01時点で全15人物が90点以上になった。追加必須だった9名には別の人物報酬CGを生成・接続し、既存CGは状況説明として残した。暫定合格4名は原寸で本文、正本デザイン、手指、接触禁止を再確認して採用を確定した。輪廻と無銘を含む全員に、能力の派手さではなく「その人物が自分で何を選んだか」が読める決め場を割り当てた。
