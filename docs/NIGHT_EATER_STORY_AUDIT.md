# 夜を食べるもの 人物物語制作監査

更新日: 2026-08-01

## 調性と人物の中心

夜を食べるものはシリアス枠ではない。姿は静かで美しいが、照明、閉店時刻、
冷蔵庫、得点板、朝日まで味見して営業を混乱させるドタバタコメディ人物である。

- 裏ボス級: 一口で夜明けを三分遅らせ、会場全体を本来の夜へ変える。
- 主な笑い: 設備の食レポ、顔写真が夜、冷蔵庫厳禁、照明係とのいたちごっこ。
- ミミの役割: 理解者として黙って座らず、閉店時刻と安全灯を守る現場責任者。
- 感情: 見えない親密さは副次。中心は、大迷惑な夜と一緒に店を回す楽しさ。
