# マリアン人物物語監査

## 役割

マリアンは15人中2～3人に限定するシリアス主調候補である。ただし、作品全体の
明るさを止める人物ではない。割れた菓子まで蘇生する規模のおかしさと、何でも
治せるからこそ治さない判断を恐れる感情を同じ場面へ置く。

## 七段階の軸

| 段階 | 物語上の役割 | 現在の固有要素 |
| --- | --- | --- |
| 出会い | 効きすぎる治療への驚き | 死者用包帯、永遠に戻るクッキー |
| 加入 | 治療記録を目的にした協働 | 脈を測る面談、本人同意の診断 |
| 信頼 | 治さない会話を試す | 割れた菓子、薬を出さない相談 |
| 覚醒 | 生死の境を読み替える力を知る | 空のベッド、戻す名を限定する祈り |
| 危機 | 休む権利まで消す契約を拒む | 責任転嫁条項、本人へ判断を返す |
| 解放 | 怖いまま自分で治療を選ぶ | 契約印を癒やさず剥がす |
| 後日談 | 自由を日常の選択として見せる | 治さない相談日、二片のクッキー、私用予定欄 |

## 評価と未完了

正式データ移行と後日談の全面改稿は完了した。後日談単体は91点。出会いから解放
には他人物と共有する抽象文が残り、人物全体は76点として未完了である。次回の
全面校閲では、同じ意味の「本人の返事を待つ」説明を減らし、包帯、受付票、脈、
治療手順の具体的な行動へ置き換える。
