# キャラクター正典と既存イベントCGの照合(2026-08-17)

## 正典の所在(重要)

キャラクターの姿の**正本は `public/assets/battle/fighters/*-v1.png`**。
コード(`src/data/characterVisuals.ts`)が実際に参照している一人絵で、黒背景・全身。

| 資産 | コードからの参照 | 位置づけ |
|---|---|---|
| `battle/fighters/*-v1.png` | あり | **正本。CG制作時はこれを添付する** |
| `story/encounters/*.png` | あり | 出会いの場面絵。**ミミが写り込む**ので単体参照には不向き |
| `story/sprites/*.png`(trueform除く) | **なし** | **非採用の旧版。参照しない** |
| `story/sprites/*-trueform.png` | あり | 真の姿(mumyo / sazanami / shahar) |

ミミ本人の姿は `story/sprites/mimi-*-v1.png` を使う(表情5種)。

### 有効だった手法

添付は3枚固定にする。**ミミ立ち絵 + `battle/fighters/<char>-v1.png`(正典) +
同作品の既存CG(絵柄見本)**。3枚目を背景ではなく既存CGにすると、絵柄と光の質が既存資産と揃う。
人型でないキャラは「**人型ではありません**」と明示したうえで姿を列挙する。

## 再発防止

1. CG制作時の添付は **ミミ立ち絵 + `battle/fighters/<char>-v1.png` + 絵柄見本** の3枚。
2. `encounters/` は構図の参考にとどめ、キャラ同一性の参照には使わない。
3. 生成物は必ず正典と並べて目視照合してから納品する(髪色・瞳・衣装・小道具・**性別**)。
