# アマラ人物物語 制作監査

更新日: 2026-07-31

## 人物の中心

アマラは契約批判の代弁者ではなく、正しさへ執着するあまり、結論のない会話や
勝敗のない遊び方を知らない宇宙規模の裁定者である。

- 裏ボス級の分かりやすさ: 重力、昨日の判決、規則そのものを被告席へ呼べる。
- 中心感情: 正しさへの執着、間違う怖さ、遊びの不得手。
- 中心の笑い: 箸袋や噴水の縁まで法的に検討する。
- ミミの役割: 正解を教えず、沈黙と未完成の続きを待つ。
- 象徴: 白い手袋、赤字の規則集、箸袋の異議、青いチョーク。

### `amara-epilogue-no-verdict-v1`

ミナトの朝の対面二人絵を反復せず、午後の噴水広場をミミの肩越しに見る。
アマラは規則集を閉じ、勝者のいない怪獣と兎の落書きの前で青いチョークを
差し出す。普段ほとんど見せない無防備な笑顔と、判決ではない誘いが読了報酬。
身体と手は接触しない。後日談の台詞「異議があるなら、隣へ描いて」の直後へ接続。
