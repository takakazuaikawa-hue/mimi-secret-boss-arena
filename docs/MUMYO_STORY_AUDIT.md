# 無銘人物物語監査

## 人物の核

無銘は、歴代所有者の望む最強の姿と名を映す剣である。強い所有者を待つ武器ではなく、自分の声だと思ったものまで他人の願いかもしれないため、誰の願いでもない声を選び分けるまで黙っていた存在として描く。

見た目の中心は人型の美丈夫ではなく、剣本体、縦長の古鏡、鏡の中にだけ現れる黒髪の人物という三層構造である。格好よさは抜刀の威力ではなく、世界を斬れる者が斬らないと自分で決める所作から生む。

## 七段階の進行

- 出会い: 展示ケースの剣と、背後の鏡にだけ立つ人物を同時に発見する。
- 加入: 所有者欄へミミの名を書けば全出力を開ける矛盾を知る。
- 信頼: 置かれて初めて退屈と休憩を知った無銘と、ケース越しに同じ時間を過ごす。
- 覚醒: 一寸の刃に十四の所有者の時代が映る。借りた名ではない呼ばれ方を探し始める。
- 危機: ミミを正式所有者にする全出力契約を拒む。
- 解放: 動けなくても、持たれないことと自分で留まることの違いを選ぶ。
- 後日談: 所有者なし搬出式で、誰にも運ばれず、剣として休み、鏡の人物として自分の足で展示室を出る。

## 後日談の再設計

旧稿の案内係と静かな影歩きは、自由の余韻はあったが、コメディの事件、無銘固有の決断、人物報酬の頂点が不足していた。

新稿は、会社規則の「解放済み景品は所有者が搬出」という自己矛盾から始める。黄金の神輿、聖獣、自走台車、近くの勇者という搬出案を全て「持たれる方法」と退け、最後に無銘自身へ行き先を尋ねる。十四の歴代勇者が最終決戦を同時発生させても、無銘は抜刀せず一指で全てを納める。本人だけが鏡から退出し、剣は有給休暇という申請結果でコメディへ戻す。
