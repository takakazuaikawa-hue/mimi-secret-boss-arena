# 制作進行プロトコル

最終更新: 2026-08-03

## 目的

「進めます」と予告して返答を終え、次のユーザー発言を作業開始の合図にする運用を
禁止する。制作は確認が必要な判断以外で止めない。

## 各返答前の状態

作業中は、次のどれか一つを明示する。

1. **作業継続中**: 確認不要。実作業を行ってから結果を報告する。
2. **確認待ち**: 方向を左右する具体的な問いを提示し、未承認部分を実装しない。
3. **実装・検証完了**: 実際に変更したファイルと検証結果を報告する。
4. **阻害中**: 技術的な障害、試した方法、残る選択を具体的に報告する。

## 禁止

- 実作業前に「次は進めます」で返答を終える。
- 質問がないのに、確認待ちのように止まる。
- 確認が必要なのに、台本案を確定仕様として実装する。
- 設計書を作っただけで、対応する実装まで完了したように報告する。
- ビルドだけで実画面確認まで通ったとみなす。

## 完了報告の条件

- 設計作業: 確定事項、仮案、確認待ちを分けて記録した。
- 実装作業: コード変更と型検査または対象テストを通した。
- 画面作業: デスクトップとモバイルの実画面を確認した。
- 物語作業: 前後の文脈、選択の結果、必要な演出資産まで記述した。
- 情報設計: 内部情報とプレイヤー情報を分類し、制作語を世界内の言葉へ翻訳した。
- 理解確認: 初見のプレイヤーが、表示された情報だけで現在の状況、選べる行動、
  選択後の変化を説明できる形になっている。

実画面確認など未完了の証拠がある場合は、その項目だけを未完了として残す。
