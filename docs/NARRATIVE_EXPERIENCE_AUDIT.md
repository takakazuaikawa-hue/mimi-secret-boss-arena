# ノベル体験監査

最終更新: 2026-07-28

## 1. 監査目的

既存コンテンツを、設定量や文字数ではなく「明るく楽しく笑えて、人へ勧めたくなる
未知のノベルゲーム体験」として評価する。システム上必要な文章と、読みたい文章を
区別し、育成や戦闘が物語を支えているかを確認する。

## 2. 現在ある強い核

### 人へ話したくなる具体的な場面

- 大魔王撃破後にしか現れないギドノゼアースが、三百年待った限定パフェの予約客。
- 世界を救った勇者が、世界の命運より昼食の券売機で長く迷う。
- 古竜の身長欄を「天気予報参照」で選手登録する。
- 規則へ異議を唱えると、重力や昨日の判決まで被告席へ呼ばれる。
- 倉庫で「世界・使用済み」を一箱だけ棚卸しする。
- 存在しない支店の歓迎会に、転生三日前の日付の辞令が置かれている。
- 何百年も窓口を離れられない番人が、十五分休止の札を初めて表へ返す。

これらは、規格外の存在を日常の手続きや食事へ真剣に置くことで成立している。
設定説明ではなく、見た瞬間に状況が分かり、短く説明しても面白い。

### 有効な文章技法

- ミミが異常を大声で説明せず、接客経験から現実的に対処する。
- 巨大な力と、小さな生活用品や食事を同じ画面へ置く。
- 相手の格を落とさず、本人だけは真剣なまま笑いを作る。
- 小道具を後の感情変化へ再利用する。
- シリアスな感情を、制度の説明ではなく手の動きや沈黙で見せる場面がある。

## 3. 現在の大きな問題

### A. 物語全体が契約論へ収束しすぎる

26週の週ナレーションは、ほぼ毎週、契約、所有、命令、自由、署名のいずれかへ
戻る。人物プロファイルも、多くが「役目や所有によって自分で選べない」「断れる
関係を得る」という同型の恐れと願いを持つ。

結果:

- 登場人物の外見と小道具は違っても、読後に残る問いが似る。
- 明るい珍事件のあとに同じテーマ解説が入り、笑いの余韻が短い。
- プレイヤーが人物を好きになる前に、作品側の結論が先回りする。
- 契約の話を進めない週が、物語上の寄り道に見えてしまう。

方針:

- 契約と解放は一部人物と全体プロットの一案へ戻す。
- 人物ごとに、承認、退屈、競争、好奇心、創作、食事、故郷、名誉、失敗、家族など
  異なる欲求と問題を持たせる。
- 週ナレーションは、その週にしか起きない事件と人物の変化を優先する。

### B. 週の文章が「同じ予定表へのテーマコメント」になっている

週ごとに固有の小道具はあるが、四行動の文章は「働く」「一人と話す」「休む」
「契約の手掛かりを探す」の言い換えが多い。どの人物が関わり、何が意外に変わるか
は選択前に弱い。

結果:

- ノベルゲームの選択ではなく、報酬カテゴリの選択に見える。
- 行動後の事件を期待するより、必要な数値を取りに行く操作になる。
- 26週を通した時、個別の週を思い出しにくい。

方針:

- 毎週に一つ、固有の舞台、問題、人物候補、視覚的な事件を置く。
- 四行動は同じ事件への四つの参加方法ではなく、異なる場面を開く入口にする。
- 確定報酬とは別に「どんな話が始まりそうか」を短い予告で示す。

### C. 人物の心理設計が同じ型へ寄っている

現在の人物プロファイルは、見かけ上の役割、恐れ、願い、誤解、理解という丁寧な型を
持つ。ただし多くが「役割を演じている」「自分で選べない」「見捨てられたくない」
へ集中している。

方針:

- 形式は残しても、中心感情を人物ごとに分散する。
- 全員をミミが理解して救う構造にしない。ミミが間違える、振り回される、教わる、
  負ける、共犯になる人物を作る。
- 笑いの種類も、規模の落差、性格の衝突、勘違い、身体性、儀式、勝負、言葉遊び、
  生活能力、世界法則などへ分散する。

### D. 試合が物語の出来事ではなく、週番号の関門になっている

大会名と紹介文には面白い発想がある。しかし、対戦相手の人物、試合中のドラマ、
試合前に積んだ人物関係の回収が薄く、勝敗が育成報酬へ寄っている。

方針:

- 各公式戦に「今回の人物ドラマ」「忘れない敵」「試合中の事件」「勝敗後の別場面」
  を持たせる。
- 戦闘システムの学習順と物語の感情曲線を同じ順序にする。
- 最終ボスは数値倍率ではなく、物語で知った人物と選択が戦い方へ戻る構造にする。

### E. プロローグの主役級フックが遅い

プロローグは状況とミミの人柄を丁寧に説明できている。一方、商品を最もよく表す
「乙女ゲームのような出会いなのに相手が規格外」という体験は、プロローグ終了後の
ギドノゼアースまで待つ。

方針:

- 転生、カジノ勤務、契約電話、派遣の事実は短く鮮明に伝える。
- 作品の中心的な笑いを、開始後早い段階で一度体験させる。
- 世界説明はギドノゼアースとの接客と最初の登録へ混ぜる。
- ページ数ではなく、最初に笑うまで、最初に選ぶまで、続きを知りたくなるまでの
  時間を測る。

## 4. 役割別再分類

| 要素 | 新しい役割 | 判断 |
| --- | --- | --- |
| ギドノゼアースとの出会い | 製品の中心を証明する最初の場面 | 最優先で磨く |
| 乙女ゲーム文法の人物イベント | 本作の中心的な語り方 | 全人物で固有化 |
| ミミの一人称 | 読者を異常な世界へ案内する視点 | 最優先で統一 |
| 週行動 | 次の物語を選び、周回差を作る入口 | 数値選択から物語予告へ |
| 育成・編成 | 人物への愛着を試合結果へ変換する手法 | ライト層向けに簡略・推奨 |
| 監督型戦闘 | 人物と選択を回収する動的な山場 | 読解可能性を優先 |
| 契約ミステリー | 全体を前へ進める現行Bプロット | 比重を下げ再評価 |
| 支配からの解放 | 一部の感情的クライマックス候補 | 全員共通の結論にしない |
| アルデバラン社の制度風刺 | コメディの一種類 | 連続使用を避ける |
| 殿堂・周回 | 別の物語とチームを試す動機 | 本編満足後の再訪理由 |

## 5. 推薦したくなる場面の合格条件

各主要人物は、次の条件を満たす固有場面を最低一つ持つ。

1. 一枚の画像または二文の説明で状況の異常さが伝わる。
2. 相手の強大さや人格を傷つけずに笑える。
3. ミミの反応が一般的な感覚と接客者としての個性を両立する。
4. その人物以外へ名前を置換すると成立しない。
5. 後の感情変化または試合で一度回収される。
6. 内部用語や設定資料を知らない人へ話しても面白い。

## 6. 次の監査

- 全15人物について、中心感情、笑いの種類、ミミが受ける変化を比較する。
- 26週について、固有事件、人物候補、選択差、試合との回収を一覧化する。
- プロローグから第4週までの実際の表示時間と文章量を測る。
- 現在の選択肢を、物語上の展開差があるものと数値差だけのものへ分ける。
