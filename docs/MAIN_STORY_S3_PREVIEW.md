# 3周目「記録外勤務週」週割りプレビュー

台本正本: docs/MAIN_STORY_SCRIPT.md 第四部/題材研究: docs/MAIN_STORY_RESEARCH_S3.md

## どんな話か(ひとことで)

**全員の名前を取り戻してきたミミが、最後に自分の名前を取り戻す話。**
会社に勝った後に残っていた、最も個人的な戦い。そして世界そのものが目を覚まし、
新しい闘技場の柿落としで、みんなが一幕ずつ舞台に立つ大団円。

## 背骨(三幕)

1. **愕然と発見(週1〜13)**: 倒したはずの会社まで再演されている——会社すら台帳の
   登場人物だった。自分の登録票を開くと「所有者: アルデバラン社、登録日: 転生当日」。
   ギルドの窓口で承認印の空欄が見つかり(手続きの瑕疵)、中点でミミは提訴する。
   「原告、ミミ」。
2. **署名の旅と、どん底(週14〜21)**: 裁定破棄には転生者の連署が要る。「時々この
   世界に存在している」転生者を探す大混乱の喜劇。だが週20、回収局がミミを台帳から
   抹消——世界がミミを見えなくなる。それでも、まかないの席は今日も一人分多く
   用意される。**世界の習慣が、ミミを覚えている**(世界の覚醒)。
3. **裁判と柿落とし(週22〜26)**: 百人目の署名(意外な人物)で存在が復元。旧会場
   最後の興行として、闘技場で開廷。裁定破棄、最後の赤線を自分の所有者欄へ。
   慰謝料は新しい闘技場の建て替え費用に化ける。決勝の相手は四百年前の「初演の
   一座」——最初の舞台と新作が向かい合って、円環が閉じる。柿落とし十五幕、
   カーテンコール、最終選択へ。

## リサーチの主な反映

- **王の帰還「ホビット庄の掃討」**: 外の戦争(会社)に勝った後の、内側のもう一戦
  (自分の所有者欄)。3周目の構造そのもの。
- **The Good Place / まどか**: 敵をもう一度倒すのではなく、ループの規則そのものを
  書き換える決着。最終選択(維持・崩壊・再構築)がその中身。
- **エンドレスエイトの教訓**: 冒頭の再演は「ほつれ」込みで見せる(役者不足の再演)。
  無自覚な繰り返しを長々と見せない。
- **34丁目の奇跡**: 署名は世論の量ではなく「欠落した手続きの当事者が今ここに
  揃っている」当事者性の証拠。承認欄の空白が主戦場。判事は敵にしない。
- **逆転裁判**: 法廷を闘技場で開く(傍聴席=観客席)。小さな矛盾の三段連鎖で逆転。
- **12人の怒れる男**: 最後の抵抗者は論理でなく私的な傷で陥落する→百人目の署名。
- **Re:ゼロ**: 「自分だけが覚えていて、証明できない」孤独を週20〜21に一場面。
- **ラピュタの庭師ロボ**: 世界の覚醒は「私にも心がある」と言わせず、誰も見て
  いなくても続く習慣(まかないの席、下駄箱の札)で描く。
- **柿落としの実文法**: 語源(屋根の木片払い)を週23の祭事に。口上は一箇所だけ。
  カーテンコールは「まとめる→分ける→独り立ち」、退場は一人ずつ自分のタイミングで。
  祭り当日は新情報ゼロ、26週で仕込んだ演目帳の回収のみ。
- **慰謝料の二段オチ**: 四百年分の算定で算盤が壊れる巨額→「新しい闘技場の
  建て替えに」+「私の名前を、返してください」。

## 新しい様式美: 二冊のノート

2周目の赤線に代わる道標。中点(週13)で同じ机に開く。

- **署名簿**: 転生者の連署が埋まっていく(違和感の軸の仲間集め)
- **演目帳**: ミミが立作者として仲間の幕を登記していく(柿落とし十五幕の仕込み)

どちらも「書く」行為——「この世界の続きは、誰が書くのか?」(Q3)が物理の二冊になる。

## 週26の大取り(いちばん良い画)

カーテンコールの最後、ミミは台帳に一つだけ書き足す——**初代記録係の名前**。
四百年間、誰にも書かれなかった人を、最後の書き手が書く。
そして最終選択: 台帳のペンを誰が持つか。
維持=ペンを置く/崩壊=台帳を閉じる/再構築=ペンをみんなへ
(演目帳が新しい台帳になる。続きは、その週を生きる人が書く)。
