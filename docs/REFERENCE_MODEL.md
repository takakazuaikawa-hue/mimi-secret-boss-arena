> **参照順位の更新（2026-07-28）**

> 人に勧めたくなる未知のノベル体験を強めない仕組みは、表内で採用済みでも再評価する。
> 育成と戦略はノベルゲームのライト層へ向けた支援手法であり、製品の主目的ではない。

## 1. 参照の階層

本作は複数作品の機能を均等に混ぜない。全体の判断に迷った場合は、必ず上位の
参照を優先する。

1. **全体骨格: 本作の確定要件**
   異形を含む仲間、3人編成、自由を賭けた競技、敗北しても続く物語を扱う。
   参照作品の解放による戦力喪失は、育てた人物を使い続けたい本作の体験と衝突する
   ため採用しない。
2. **期間育成: パワプロのサクセス／栄冠ナイン**
   限られた期間、日程選択、蓄積した育成資源、重要局面だけの監督采配を借りる。
3. **週行動の機会費用: モンスターファーム**
   仕事、交流、休養、探索が別の目的を持ち、同じ週に全部は得られない構造だけを
   借りる。寿命、疲労、資金0ゲームオーバーは採用しない。
4. **自動戦闘の文法: ユニコーンオーバーロード**
   編成、位置、装備、事前作戦が自動戦闘の結果へつながる構造を借りる。
5. **交流の見せ方: ときめきメモリアル Girl's Side**
   明るい期間表示、予定によって出会う相手が変わる予感、イベント回想だけを借りる。

## 2. 設計追跡表

| 領域 | お手本の仕組み | 本作への変換 | 採用しないもの | 合格条件 |
| --- | --- | --- | --- | --- |
| 全体循環 | 自由を目指す物語と3人編成を同じキャンペーンに置く | 26週で裏ボスを集め、3対3を戦い、条件を満たした人物の契約を解く | 解放による強制離脱 | 解放後も同じ人物を育成・編成・出場できる |
| 敗北 | Pyreは敗北後も進み、物語が結果を受け取る | 次の公式戦には出られるが、賞金、追加戦、育成P、最終戦力の上限を失う | リトライ前提、無損失 | 敗北で進行不能にならず、勝敗の期待値差は明確 |
| 解放 | 条件を満たした人物だけ関係が変化する | 12、20、25週の機会に契約を解除し、自由契約の仲間として残る | 強制離脱、再契約による戦力維持 | 所有0になり、戦力・装備・育成可能状態は維持される |
| 期間育成 | パワプロは限られた期間の行動と重要試合で選手を成長させる | 毎週一行動、試合と個別事件で固有P、希少な選択で共有P | 週を使う手動トレーニング | 行動だけを繰り返しても最強にならない |
| 週行動 | モンスターファームは命令ごとに利益と費用が異なる | 働く=資金、遊ぶ=信頼、休む=体調、探す=新規候補と契約進行 | 疲労、寿命、死亡、0G終了 | どの行動にも他行動の主報酬を混ぜない |
| 仲間集め | 期間内の限られた加入と編成選択 | 3人目までは第1公式戦の安全網。4人目以降は探すが主経路 | 週数に応じた自動人数補填 | 探さない方針の平均所属は5人未満 |
| 自動戦闘 | ユニコーンオーバーロードは事前作戦に基づき自動解決 | 前中後衛、個別AI、装備、全体方針を準備し、重要局面だけ介入 | 毎手の直接コマンド | 同戦力でも準備と介入で勝率差が出る |
| 交流 | GSは予定選択から人物イベントへつなぐ | 注目選手と行動適性で続きの確率を上げる | 恋愛成就、身体接触 | 選択前に続き候補を示し、確定とは表示しない |
| 周回 | 限られた期間と分岐する結果 | チームは殿堂保存し、キャンペーンへ持ち込まない | 永続強化による周回の易化 | 新周回の初期戦力は毎回同じ |

## 3. 数値上の拘束条件

- 第1週はギドノゼアース固定。第3週終了までに出場可能な3人を保証する。
- 4人目以降の新規遭遇率は、通常営業の「探す」で48%を基準とする。
- 探す以外の偶然遭遇は2〜7%を基準とし、所属が増えるほど下がる。
- 探すには800Gを使う。資金不足でも選べるが、遭遇率は下がる。
- 毎週の出場者への自動固有P配布を廃止する。
- 働くは資金、遊ぶは信頼、休むは体調だけを確定報酬にする。
- 勝利時の出場者は固有P+4、敗北時は+1。敗北にゲームオーバーはない。
- 解放機会は12、20、25週。各機会で一人だけを扱う。
- 解放した選手は自由契約として、その周の出場・育成・装備対象に残る。
- 解放イベントの選択は、自由にするか否かではなく、自由な相手へ今後をどう頼むか
  を扱う。どちらも解放として再構築条件へ数える。

## 4. 制作ゲート

### Gate A: 骨格

- 26週を最後まで進められる。
- 資金0、全敗、解放0でも進行不能にならない。
- 勝利、探索、解放の選択が最終チームを別の形にする。

### Gate B: 数値

- 300以上の固定シードで「探索なし」「探索重視」「信頼重視」を比較する。
- 探索重視は探索なしより平均所属が1人以上多い。
- 探索なしで6人以上になる割合を15%未満にする。
- 勝利数と最終チーム能力に正の相関がある。

### Gate C: 体験

- 行動選択前に「何を得て、何を諦めるか」が一画面で読める。
- 解放画面で「契約は終わるが、本人の意思で在籍・育成・出場を続ける」と分かる。
- 敗北結果で、失った賞金、追加戦、育成差と、次へ進める事実が分かる。
- 戦闘は行動者、対象、技、HP/BREAK変化、監督指示の結果が時間順に読める。

### Gate D: 内容追加

人物、事件、装備を追加する前に、既存の3方針シミュレーションを通す。追加内容が
平均所属、解放数、資金、勝率を許容範囲から外した場合は、内容ではなく基礎式を
無理に補正せず、その追加内容の報酬を調整する。
