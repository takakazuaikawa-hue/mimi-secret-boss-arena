# 3周目のための題材リサーチ(2026-08-15)

3周目「記録外勤務週」を名作にするため、4方向の先行作品研究を行った。
本書はその要点と、本作への適用原則の登記。台本への反映は
docs/MAIN_STORY_SCRIPT.md 第四部が正本。

## 1. 三部作の最終章の構造(何が満足を作るか)

- **Breaking Bad**: 新しい仕掛けで驚かせず、最初から約束していた終わりを誠実に
  やり切る。外の事件の決着と、主人公の内面の告白を同時に着地させる。
- **The Good Place**: 制度を「倒す」のではなく**勝利条件そのものを作り替える**。
  そして全員一斉のフィナーレにせず、各人が**自分のタイミングで**区切りを迎える。
- **王の帰還「ホビット庄の掃討」**: 外の大戦争に勝った後、**もう一つの小さくて
  個人的な戦い**を課す。勝利後の弛緩を防ぎ、旅の意味を身近な場所に翻訳し直す。
  → 3周目の構造そのもの: 会社(外)に勝った後、残るのは自分の所有者欄(内)。
- **失敗例(GoT/LOST)**: 人物の急変を蓄積なしで置く/謎を約束して回収しない。
  → 教訓: **謎の設定回収より、人物間の感情的決着を優先**。反転は1つに絞る。
  新規の謎を終盤に足さず、既存要素の**再文脈化**だけを行う。
- 勝利後の緊張は「新たな敵の強さ」ではなく「**積み上げたものを失う可能性**」で作る。

## 2. ループ・メタ物語の終わらせ方

- **まどか☆マギカ**: ループを生む**規則そのものを書き換える**。代償は一点に絞る。
- **シュタインズ・ゲート**: 力ではなく知略と忍耐。代償=自分だけが全てを覚えている孤独。
- **Re:ゼロ**: 記憶の非対称(自分だけが覚えていて、証明できない)こそが呪いであり
  成長の証。→ 最終盤に「ミミだけが会社を倒した記憶を持ち、誰にも証明できない」
  孤独の一場面を置く。
- **エンドレスエイトの教訓**: 反復を見せるなら、**増分のシグナルを早く外化する**。
  無自覚な繰り返しを長々と見せない。→ 3周目冒頭の再演は「ほつれ」込みで見せる。
- **時をかける少女**: 有限の力を使い切り、**他者へ渡す**ことで終わる。
- **moon / Undertale / NieR:Automata / OneShot**: ゲームは「終わり」をプレイヤーの
  実操作として体験させられる唯一のメディア。→ 最終選択はUI上の実操作にする
  (保存形式は変えない。演出と選択肢の範囲で)。
- **ネバーエンディング・ストーリー**: 「続きは誰が書くのか」の答えを抽象にせず、
  **具体的な一人への引き継ぎ**として描く。
- **世界の覚醒の条件(ラピュタ庭師ロボ型)**: 「私にも心がある」と言わせない。
  **誰も見ていなくても続く習慣的行動**で示す。覚醒には脆弱性・代償を伴わせる。
  クライマックスで新設定として初出ししない(既存テーマに接続する)。
- メタの失敗要因: 仕掛けが感情の伏線と接続されず、既存の緊張を後出しで無効化する。

## 3. 裁判クライマックス(署名の奇跡)

- **34丁目の奇跡**: 「サンタは実在するか」を証明せず、「政府機関がサンタとして
  扱った」という**手続き的事実**へ論点を移す。物量(手紙の山)は制度の別の歯車が
  生んだ副産物で、制度の言葉が思いがけず個人の側に立つのが泣かせの核。
  → 署名は世論の量ではなく「**欠落した手続きの当事者が、今ここに揃っている**」
  という当事者性の証拠として提出する。承認欄の空白=手続きの瑕疵が主戦場。
- **逆転裁判**: 大逆転を一発で狙わず、**小さな矛盾の連打(三段以上)**で将棋倒しに。
  法廷そのものを観客のいる興行として設計する。→ 審理を闘技場で開く。
- **12人の怒れる男**: 相手を論破せず「もう一度検討しよう」で**自分で気づかせる**。
  最後の抵抗者は論理でなく、私的な傷の露呈で静かに陥落する。
- **敗者の品位**: 敗訴側(制度)に (a)理解可能な動機 (b)最後の一瞬の良心、の
  どちらかを必ず残す。完全な悪役として制度を描くと勝利が安っぽくなる。
  判事は一枚岩の敵にせず、最後は**制度の言葉で救いに転じる側**に置く。
- **判決は二段構成**: 制度の言葉(正式裁定)→人間の言葉(私見の一言)。
- **慰謝料は二段オチ**: 法外な算定額(笑い)→本人が象徴的な形へ切り替える(感動)。
  金額そのものより「なぜその額なのか」の一言が笑いと感動を分ける。
- 署名提出の画は「山」ではなく「**一枚の差出人が見える瞬間**」。意外な差出人を
  一人仕込み、法廷で名前が読み上げられる瞬間を作る。

## 4. 柿落とし・祝祭の大団円

- **柿落としの語源**: 「こけら」=建築の最後に屋根から払い落とす木片。**建物の
  完成と場の生まれ変わりを祝う儀式**が起源。→ 週23の上棟・こけら払いで語源を
  街のみんなの手作業として見せられる。
- **口上の文法**: 「東西東西」で開き「隅から隅までずずずいっと」で結ぶ。演技を
  止めて素の声で観客に語る「切り口上」は**一箇所だけ**使う(多用すると冗長)。
- **番組の様式**: 一番目(時代物)・二番目(世話物)、最終幕=大切り(大喜利の語源)は
  縁起よく華やかに締める。**立作者**が座頭と「世界」を決め全体を統括する
  → ミミ=立作者、が正典の「大取りを起草する」と一致。
- **序破急**: 静かな導入→情念の蓄積→加速。15幕の並びにも、26週の仕込みの
  配分にも入れ子で適用(序盤ゆっくり登記→中盤密度を上げ→終盤追い込み)。
- **カーテンコールの作法**: まとめる(端役数人ずつ)→分ける→独り立ち(主役単独)、
  の密度の三段。退場は一斉にせず、**一人ずつ自分のタイミングで**(オーシャンズ11の
  噴水+The Good Placeのドア)。
- **全員参加型(サマーウォーズ)**: ルール理解でなく「誰かのために誰かが動く」連鎖の
  可視化が全員参加感を作る。
- **興行の肯定(グレイテスト・ショーマン)**: 見世物性の搾取を一度作中で自覚させ、
  その上で「見られることを自分の意志で選び直す」と切り返してから肯定する。
  批判を経由しない祝祭は薄い。
- **本命と全員祝福の両立**: 「全員に台詞、一人にカメラ」。本命以外の14人にも
  固有の台詞と小さな決着を与えた上で、単独カットは本命だけに割く。
- **祭り当日は新情報ゼロ**: 26週で仕込んだものの回収だけに使う。「もう知っている
  ことが形になる」満足を作る。

## 適用の総則(3周目執筆規則)

1. 反転(会社もループの登場人物だった)は冒頭で使い切り、以降は新規の謎を足さない。
   回収するのは既存の仕込みのみ(黒角封筒、演目表、週19「額の裏の紙の跡」、
   1周目w25「緊急回収リスト: ミミ様(無形)」、s2w15「なぜ覚えているのか」)。
2. ループを終わらせる行為=規則の書き換え。代償は一点。力の再演(もう一度倒す)に
   しない。
3. 世界の覚醒は台詞でなく習慣で描く。山場は週21「見えない一週間」に集約。
4. 裁判は闘技場で。手続きの瑕疵+当事者の連署で勝つ。敗者に品位を残す。
5. 柿落とし当日は回収のみ。仕込みは26週に序破急で配る。
6. Q3の答え(続きは誰が書くか)は、抽象でなく具体的な引き継ぎの画で出す。
