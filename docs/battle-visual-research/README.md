# Battle Visual Research

This folder records battle-screen concepts used to validate hierarchy and state
changes before implementation. These images are design studies, not shipping
assets.

- `concept-a-auto-watch.png`: normal AUTO observation and next-action forecast
- `concept-b-break-impact.png`: impact frame with HUD suppression and staged result
- `concept-c-spectator-bet.png`: post-defeat 2v2 spectator betting climax
