# リンネ人物物語監査

## 役割

リンネはドタバタコメディ主調である。運を操作して必ず勝つ人物ではなく、胴元が
勝つ未来や外れだけを避けられる。無一文でも賭けを始め、存在しないものまで賞品へ
巻き込む一方、最後には安全な未来を選ばず、見えない結果そのものを楽しめるようになる。

## 後日談CGの再監査

最初の `rinne-epilogue-zero-stakes-cup-v1.png` は大会の面白さを説明する状況CGとしては成立するが、輪廻本人のクライマックス報酬としては弱いと再判定した。

そこで `rinne-epilogue-edge-standing-reward-v1.png` を追加した。輪廻の未来視を無数の金色の軌跡として見せ、その全てが縁で立つ一枚のコインへ収束する。輪廻は未来を見ず、ミミは自分の札を握って対等に向き合う。二枚の札が一つの予定になる本文の決着と一致し、輪廻固有の小粋さ、勝負師の格、静かな高揚を一枚で伝える。

採用時に余分な三枚目の札と大きすぎる手を検出したため、修正版では札を二枚、コインを一枚に限定し、手の比率と指を再生成している。
