# 第一勤務週・メインストーリー骨子「存在しないチームの凱旋試合」

三段階キャンペーン第一区分の背骨。再生は**メイン→個別**の二段構え。
個別7場面(改稿済み)は無改変で、入口の状況だけをメイン側が作る。

## 1. 主軸

初日、モップを持ったミミの頭上で大掲示板が点灯する。
「本日より賭け受付開始——ミミのチーム、復帰戦!」。
世界中がとっくに賭け終わっている伝説の興行。監督室にはミミの名前、
彼女のサイズのコート、彼女の筆跡のサイン色紙、まだ開催されていない
大会の「二度目の優勝」プレート。そして受付が差し出す選手名簿は——白紙。

**世界で一番期待されている監督が、選手ゼロ・記憶ゼロ・入社初日。**
締切までに、見たこともない自分のチームを実在させる。
スカウトも育成も第4週の大会も、全部この一つの無茶の中で起きる。
第4週の初心者大会(opening-cup)は、この「復帰戦」として再演出する
(試合定義・報酬は不変。文脈だけ主軸に接続)。

笑いの芯: 結果だけが先にある世界で、原因を自分の手で作りに行く。
美しさの芯: 存在しないチームを、世界は三百年信じて賭け続けていた。

## 3. 異常の種(言葉で説明しない現象)

- まだ開催されていない大会の「二度目の優勝」プレート
- 監督室の備品が全部ミミ仕様(コートのサイズ、色紙の筆跡)
- 三百年前の「前回の凱旋戦」の写真に、今日と同じ影
- ファンクラブの会員番号が三桁まで埋まっている
- 「復帰戦」——誰も「一回目」を覚えていない

命名(「クリア後」「ループ」等)は第二区分まで作中で禁止。

## 4. 橋の規則

- メイン各話の末尾は、その週の個別meetの入口の状況を発生させて終わる。
- 脇4人はメイン側では一場面+一言まで。掘り下げは個別へ。
- 遭遇済み周回(区分やり直し)ではfollowupを出さず、末尾の受け行のみ分岐。

## 5. 実装(二段再生) — 実装済みの骨組みを踏襲

- 週固定差し込み: chooseWeeklyAction のhotSpring前例と同型(実装済み: 週1)
- 連続再生: continueEvent のfollowup連鎖に maybeCreateMainStoryFollowup(実装済み)
- ブロック: kind "opening" で openingBlocks.ts へ登録(ep1実装済み、ep2〜5は同型)
- 進行はeventHistory+週番号。第2〜5話の週固定条件を追加時に実装
