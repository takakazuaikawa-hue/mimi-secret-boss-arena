# 第一勤務週・メインストーリー骨子「初出勤と、この街のふつう」

三段階キャンペーン第一区分の背骨。再生は**メイン→個別**の二段構え。
個別7場面(改稿済み)は無改変で、入口の状況だけをメイン側が作る。

## 1. 主軸(1周目=この世界の理解と愛着)

**第1週は「ふつうに面白い初出勤の話」で、それ自体がチュートリアル。**
両替所に竜が並び、売店で幽霊が新聞を買い、従業員がチームを持つのが
福利厚生の街を、新人の目で一周する。週行動(働く/遊ぶ/休む/探す)は
業務表の引き継ぎとして自然に説明される。

チーム結成は「新規チーム立ち上げ届」という、この街ではありふれた
事務手続きとして始まり、第4週の初心者大会へ素直につながる。

**謎は告知しない。** 種は一粒まで(例: すれ違うご老人の「今年も応援して
いますよ」)、ギャグのテンポで通過させ、二周目に意味が変わるようにする。
語り手が異常を「変だ」と指摘したら、それは告知なので禁止。
「復帰戦」の看板・監督室・二度目の優勝プレート等の大掛かりな異常は
**二周目以降の前景**へ送る(1周目の画面には出さない)。

三周の感情設計(正本・docs/GAME_DESIGN.md §4):
1周目=理解と愛着 / 2周目=不思議さを少しだけ+大目標(闘技場の解放と打倒)
のクリア / 3周目=世界の覚醒とどんちゃん騒ぎの大団円。

## 3. 異常の種(言葉で説明しない現象)

- まだ開催されていない大会の「二度目の優勝」プレート
- 監督室の備品が全部ミミ仕様(コートのサイズ、色紙の筆跡)
- 三百年前の「前回の凱旋戦」の写真に、今日と同じ影
- ファンクラブの会員番号が三桁まで埋まっている
- 「復帰戦」——誰も「一回目」を覚えていない

命名(「クリア後」「ループ」等)は第二区分まで作中で禁止。

## 4. 橋の規則

- メイン各話の末尾は、その週の個別meetの入口の状況を発生させて終わる。
- 脇4人はメイン側では一場面+一言まで。掘り下げは個別へ。
- 遭遇済み周回(区分やり直し)ではfollowupを出さず、末尾の受け行のみ分岐。
