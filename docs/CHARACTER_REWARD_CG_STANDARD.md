# 人物ご褒美CG基準

## 目的

コメディの状況が分かるだけの一枚絵を、人物ルートのご褒美CGと呼ばない。
ご褒美CGでは、騒動の中でその人物が最も格好よく、小粋で、魅力的に見える瞬間を
選ぶ。笑いと人物の格を同時に成立させる。

## 二種類の役割

- 状況CG: 人物、場所、小道具、騒動の規模と落ちを一目で伝える。
- ご褒美CG: 情報量を絞り、人物固有の決断、能力、視線、距離を感情の頂点にする。

一枚で両立しない場合は、状況CGを削らず、ご褒美CGを別に追加する。

## ご褒美CGの採用条件

1. 他人物へ置き換えても成立する構図ではない。
2. その人物の能力や生き方が、最高に格好いい選択として見える。
3. 立ち姿、手、視線、小道具、色設計のどれかに決めの瞬間がある。
4. ミミも受け身の添え物ではなく、相手の魅力を引き出す選択をしている。
5. 接触や恋愛記号に頼らず、二人の距離が動いたことが分かる。
6. コメディの名残を小道具や背景へ残しても、人物の格を落とさない。
7. 正式人物デザインと`MIMI_VISUAL_BIBLE.md`を満たす。

## 禁止する代用

- 群衆と小道具を増やしただけの集合絵。
- 正面で見つめ合うだけの汎用的な二人絵。
- 泣き顔、顔の近さ、光量だけで感動を作ること。
- キャラクターを騒動の被害者や説明役に留めること。
- コメディを優先して本人の強さ、知性、美しさを崩すこと。
