# さざなみ人物物語 制作監査

更新日: 2026-08-01

## 人物の中心

さざなみは、人間の姿へ変わって交流する海の美形ではない。海溝より大きな水流と
単眼の異形であり、寝返りで沿岸三県の潮位を変える一方、市販弁当の青のりを
四十二点と断じる規模差コメディ人物である。

- 裏ボス級: 地上に映った影だけで闘技場を海底へ変え、本体の寝返りで海岸線が動く。
- 主な笑い: 地理災害級の動作と、青のりの乾きや塩加減への細かすぎる採点。
- ミミの役割: 巨大生物を人間化する相手ではなく、胴長を着て弁当を救う品評会運営者。
- 感情: 小さな暮らしを壊さない距離を覚え、思い出の安い弁当を自分から返しに来る。

## 画像監査

- 正式立ち絵: 深青の海流と巨大な単眼。異形性と裏ボス級の規模が明瞭。
- 出会いCG: 巨大眼はあるが、さざなみとは別に青髪の魚人青年が登場し、同一人物に見える。
- 解放CG: 巨大な人魚女性として描かれ、正式立ち絵と造形が一致しない。ミミも旧衣装。
- 後日談CG: `sazanami-epilogue-seaweed-awards-v1.png`を採用。

後日談CGは、巨大単眼を人間化せず水槽の主役にし、黄色い胴長のミミ、和装、魔界、
月面の参加者が弁当を頭上へ救う瞬間を描く。採点係だけが水中で記録を続け、安い弁当が
小台に残るため、「裏ボスが青のりを審査する」事件の規模と落ちを台詞なしで読める。
