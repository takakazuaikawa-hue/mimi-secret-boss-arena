# バトル視覚体験仕様 v4

## 目的

本作のバトルは、複雑な操作を要求する場ではなく、育てた裏ボス級の選手が何を考えて動き、なぜ勝敗が変わったかを、見て、期待し、次周の育成へ結びつける場である。

達成する体験は次の三つ。

1. 一秒で「誰が優勢で、今誰が動くか」が分かる。
2. 三秒で「次の技が何を狙い、どこが見どころか」を期待できる。
3. 決着後に「次は別の編成・技・賭け方で見たい」と思える。

## 調査から採用する原則

### 自動戦闘は方針選択、表示速度は別の操作にする

『龍が如く8』公式マニュアルは、オートバトルをONにした選手が事前に選んだ方針で
行動し、速度・一時停止・敵味方のHP/MP表示を別の役割として扱っている。本作も
選手のAI方針と文章送りの手動/AUTOを混同せず、どちらでも同じ戦闘内容を見せる。

出典: [龍が如く8 WEBマニュアル](https://manual.sega.jp/ryu-eight/jp/)

### 視線を動作順に誘導する

『メタファー：リファンタジオ』のUI設計では、選択した情報から次に必要な情報へ視線が自然に移ることが重視されている。本作も常設情報を並べるのではなく、`行動者 -> 技予告 -> 対象 -> 結果`の順に強調点を移動する。

出典: [Game Informer - Fantasy Fulfillment](https://gameinformer.com/feature/2025/05/01/metaphor-refantazio-cover-story-fantasy-fullfilment)

### フェーズごとに操作と情報を分ける

『Fate/Grand Order』はタクティカル、コマンド、味方行動、敵行動を分け、同じ画面に全操作を常時載せない。本作も通常観戦中、重要指示、攻撃演出、結果学習を別状態として扱う。

出典: [Fate/Grand Order 公式バトルガイド](https://www.fate-go.jp/howto/manual/4.html)

### 自動戦闘でも、準備と観察が戦略になる

『ユニコーンオーバーロード』は条件つき戦術を事前に組み、戦闘中はユニットの行動を見せる。本作では週の育成、編成、技傾向、信頼による指示可能範囲を準備とし、バトル中はAIの選択理由を短く見せる。

出典: [Unicorn Overlord 公式サイト](https://unicornoverlord.atlus.com/?lang=uk)

### 不確実性は、理解できる手掛かりと即時反応を伴わせる

不確実な成功が楽しいのは、結果が不明なだけでなく、プレイヤーが手掛かりを読み、予測を更新できる場合である。入力や行動には即時かつ明瞭な反応が必要で、説明不能なランダム結果は採用しない。

出典: [Mastering uncertainty: A predictive processing account of enjoying uncertain success in video game play](https://pmc.ncbi.nlm.nih.gov/articles/PMC9363017/)

## 画面状態

### 1. OBSERVE / 通常観戦

- 戦場と選手で画面の72%以上を使う。
- 常設HUDは外周だけに置く。
- 行動順、両陣営HP、公式戦名、AUTO/速度だけを常設する。
- 本文は18px以上、主要数値は24px以上、補助ラベルも14px未満にしない。
- 次に動く選手は輪郭光、接地影、行動順の三箇所で同じ色を使う。
- 1対1では左右一体ずつ、2対2では前衛と後衛を明確に分ける。人数の水増しはしない。

### 2. FORECAST / 技予告

- 技名を一つだけ大きく表示する。
- その横に、今回見るべき要素を最大二つだけ表示する。
- 例: `命中 94%`、`BREAK 有効`。
- AIの理由は一文だけにする。例: `盾が薄い相手を狙った`。
- この状態で0.55〜0.9秒の予備動作を見せる。高速時も0.32秒未満にしない。

### 3. ACTION / 移動と発動

- 常設HUDを35〜55%まで弱める。
- 行動者を10〜18%拡大し、`transform`だけで前進させる。
- 技名カットインは0.45〜0.75秒。画面全体を覆わない。
- 2対2でも非行動者の位置を保ち、誰が誰を狙ったか見失わせない。

### 4. IMPACT / 衝突

- 接触点、対象、ダメージの三つを同じ視野に置く。
- 70〜110msのヒットストップを入れる。
- 画面振動は4〜8px、120ms以内。常時揺らさない。
- 接触、ダメージ、HP変化の順で40〜90msずらして表示する。
- パーティクルは接触点中心、同時12個程度を上限とする。

### 5. RESOLVE / 高揚判定

三段判定は、会心、BREAK、逆転、最終局面、賭け対象などの重要行動だけに使用する。通常攻撃には使わない。

1. `命中`
2. `防御/BREAK`
3. `会心/特性/運命`

- 各灯は0.28〜0.5秒間隔で明かす。
- 最後の灯だけ0.65〜1.1秒ためられる。
- 実際の確率と表示を一致させる。
- 外れを当たりに見せかける偽の寸止めや、表示確率の操作はしない。
- 同じ試合での使用は原則3回以内とする。

### 6. RESULT / 学習

- 勝敗を最初に全画面近くで0.8〜1.2秒見せる。
- 直後に「勝敗を変えた一手」を一つだけ提示する。
- 詳細ログ、技使用数、被ダメージは任意で開く。
- 次周の目標に変換できる文にする。例: `黒星が最大ダメージを出した。次は魔力を伸ばすと再現しやすい`。

## AUTOと文章送り

- `AUTO`はAIが戦闘行動を選ぶモードであり、戦闘内容を見せずに進める機能ではない。
- 通常は、技予告、発動、衝突、結果を順に再生する。
- プレイヤーが文章送りAUTOを明示的に選ばない限り、解説文と物語文はクリックで進む。
- 重要指示、賭け、撤退、選手交代、物語選択では必ず停止する。
- 速度は`1x / 2x`。必殺技初見、解放技初見、最終判定は2xでも最低可読時間を保つ。

## 観戦・賭け

- 敗退後の観戦は本戦と同じ戦場を使い、別の小窓にしない。
- 賭けの締切前だけ、対象、予想勝率、配当、賭け金を大きく表示する。
- 締切後は入力UIを消し、`BET LOCKED`、賭け金、的中時配当だけを残す。
- 決着前の三段判定は、試合上の命中・防御・特性を可視化する。スロットやルーレットを模倣しない。
- 結果後は配当だけでなく、予想を当てた根拠または外した要因を一つ示す。

## 実装技術

- 既存依存の`motion`を状態遷移、前進、ヒットストップ、HUD抑制に使う。
- 既存依存の`howler`を予告、接触、灯の点灯、決着の四系統に使う。
- 新しい重量級レンダリングエンジンは導入しない。
- アニメーションは`transform`と`opacity`を中心にし、レイアウト再計算を避ける。
- 無限パーティクル、常時ブラー、巨大なBase64画像、毎フレームReact state更新は禁止する。
- `prefers-reduced-motion`では移動量、振動、点滅を減らし、状態変化は色と文字でも伝える。

## 画像要件

- 選手は戦場用の全身または全形アセットを持つ。
- 人型立ち絵をそのまま並べるのではなく、前後移動、接地、対象方向を統一する。
- 敵を仮の共通画像で済ませない。チュートリアル敵も専用の読める外形を持つ。
- ミミの実況顔は既存キャラクター規定に一致する表情差分を使う。
- 背景はキャラクターより一段彩度とコントラストを落とす。

## 合格基準

- 1366x768で主要本文18px相当を確保する。
- 1秒静止画テストで、行動者、対象、優劣を第三者が答えられる。
- 3秒静止画テストで、次の技と見どころを答えられる。
- 1対1と2対2の両方で選手が重ならず、HPと対象線が対応する。
- AUTOで一試合見ても、通常、注目、決着の三段階が区別できる。
- 低モーション設定でも勝敗理由が理解できる。
- 開発中のCPU負荷を増やす常駐監査ブラウザや無制限アニメーションを残さない。

## 実装済みサイズ基準

立ち絵ファイルの透明余白ではなく、キャラクター設定上の体格を表示へ反映する。

| 階級 | 基本倍率 | 2対2倍率 | 用途 |
| --- | ---: | ---: | --- |
| small | 0.84 | 0.86 | ピヨゼリー、魔導コウモリなど |
| standard | 1.00 | 1.00 | 標準的な人型、コボルトなど |
| large | 1.06 | 1.14 | 封印体ギドノ、巨人、扉型など |
| giant | 1.12 | 1.20 | 古竜、巨大海棲異形、鏡中の巨体など |

- 1対1ではもともとの表示枠が大きいため基本倍率を使う。
- 2対2では横幅の広い異形が`object-fit: contain`で人型より小さく見えないよう補正する。
- モバイルは隣接キャラクターとの衝突を避けるため基本倍率へ戻す。

## 実装済み敗退後フロー

1. 敗退結果で`他選手試合を見る`または`今回は帰る`を選ぶ。
2. 他選手4名からなる二対二カード、実力評価、配当を比較する。
3. `0 / 200 / 500 G`から賭け金を選ぶ。0 Gでも観戦できる。
4. 賭け金は観戦開始時に一度だけ差し引き、再読込や二重操作では再課金しない。
5. 観戦はAUTOで進み、`先手 / 連携 / 決着`の三段階で能力差を見せる。
6. 決着後に払戻しを確定し、自分の敗退結果へ戻る。資金0でもキャンペーンは継続する。
