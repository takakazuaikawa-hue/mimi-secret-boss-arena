# メインストーリー題材リサーチ:「クリア後の世界」の文法

2026-08-14 実施。Web調査に基づく。台本(MAIN_STORY_SCRIPT.md)の裏付け資料。

## 1. 裏ボス(隠しボス)というゲーム文法

- 裏ボスの本質は**「世界最強なのに、物語の主役になれなかった存在」**。本編の勇者は
  裏ボスに会わないままエンディングを迎えられるし、多くのプレイヤーは実際に
  会わずに終える。「強さ」と「物語上の出番」が完全に切り離されている——
  これが裏ボスの孤独と滑稽さの源泉。
- 系譜: DQ5エスターク(隠しダンジョン最深部で眠り続ける)、DQ6ダークドレアム
  (本編ラスボスを一撃で葬る=本編が余興だったと示す)、FF5オメガ・神竜(本編の
  因果と無関係に徘徊する最強)、P3エリザベス(進行係こそが最強)、
  クロノDS夢喰い(クリア後が外伝を語る)。
- 「一作に一体、エンドゲームの奥で自分の用事を済ませながら待っている」のが様式。
  **「誰にも会われないまま、ただそこに居る」**感覚が重要。

## 2. クリア後施設の文法

- **カジノ**: 本編の緊張から切り離された「遊びの飛び地」。バニーガールはその顔。
  DQの「ぱふぱふ」=必ず期待を外すスカしの伝統芸(色気を期待させて別のもので返す)。
- **闘技場**: 「戦闘だけを物語から切り出して施設化する」文法(DQ格闘場、
  バトルロード=自分は戦わず監督する、FFコロシアム)。観客・賭け・報酬の三点で
  戦闘を興行へ変換する。**負けても終わらない戦い**は、一発勝負の本編への救い。
- **真エンディング**: 通常エンディング後にクリア後コンテンツを経て開く本当の結末。
  「エンディングは終わりではなく、真の物語への入場券」という構造をプレイヤーは
  すでに学習している。

## 3. 「終わったあと」もの作品の感情

| 作品 | 取り出す感情 |
|---|---|
| 葬送のフリーレン | 郷愁と喪失からの再生。「冒険の終わりから物語が始まる」 |
| はたらく魔王さま! | 転落の解放感と第二の人生。征服の野心を時給へ矮小化する落差 |
| まおゆう | 「魔王を倒せば終わり」の構造自体を解体する知的カタルシス |
| Helck | 闘技大会を入口に、ギャグから制度の裏側へ反転 |
| 魔王城でおやすみ | フェーズ構造: ①ギャップの笑い→②個別の関係→③客同士の関係を主人公が解きほぐす |

## 4. 複数世界ハブの提示技法(Fate/スマブラ/異世界食堂)

- 共通フォーマット(クラス/フィギュア/メニュー)へ流し込む。
- 出典世界は**来歴の一場面か必殺技一つに圧縮**して見せる。長い説明はしない。
- **施設側のルール**(場内に因縁を持ち込まない等)が世界観の衝突を吸収する。
- 常連化・あだ名・指定席の積み重ねで「新しい共同体」を育てる。

## 5. 本作へ適用する十の源泉(要約)

1. **「最強なのに、誰も会いに来なかった」**——闘技場は初めて観客がつく場所。カタルシスの本丸。
2. 強さの物差しが壊れる笑い(各世界の最強同士が初めて「負け」を知る)。
3. 「本編の勇者」への複雑な片想い(一度でいいから全力の自分と戦ってほしかった)。
4. 肩書と日常業務の落差(破壊神がシフト希望を出す)。
5. バニーガール=スカしの伝統(色気を期待されて経営手腕で返す)。
6. 眠り続けた年月の郷愁(自分の世界の「その後」を伝聞で知る)。
7. 興行=負けても終わらない戦い(また明日戦える、という救い)。
8. 真エンディング文法の転用(**この闘技場での日々が、あの人たちの真エンドルート**)。
9. ハブのルールが生む群像(場内の掟、常連、指定席)。
10. **ミミ自身が「本編を持たない」存在**——物語に選ばれなかった者が、物語を
    終えた者たちの居場所を作る。彼女こそこの場の真エンディングの条件、という反転。
