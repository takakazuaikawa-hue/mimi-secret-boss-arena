# ミミの衣装設定書

主人公ミミの衣装を場面に応じて描き分けるための仕様。イベントCG生成時は、該当する
衣装立ち絵を添付して「衣装は添付のものを維持」と指定する。

**維持する要素(全衣装共通)**: 顔立ち・琥珀色の目・茶色の長い巻き髪・黒と赤の兎耳・
赤いリボンの髪飾り・体型・身長のバランス。絵柄と塗りは `sprites/mimi-*-v1.png` に合わせる。

## 1. 制服(既存・正典)

`sprites/mimi-smile-v1.png` ほか5表情。赤い燕尾服＋黒いコルセットドレス＋黒タイツ。
闘技場での勤務中はこれ。

## 2. 浴衣(温泉旅館「鏡見の湯」/ 第5週・アマラbond)

女性が「着てみたい」と思う浴衣にする。2026年のトレンドと正しい着付けに基づく。

### 色と柄
- 地色は**くすみカラー**(ダスティピンク、またはアッシュグレー)。作品の赤はここでは
  差し色として帯締めや鼻緒に回し、地色をトレンド寄りにする
- 柄は**レトロモダン**。大ぶりの椿を線描き＋水彩調でまばらに配置。小花を敷き詰めない
- 色数を絞る(地色＋柄2色＋差し色1色まで)

### 着付け(ここを外すと台無しになる)
- **右前**(着る人から見て右の衿が先、左が上に重なる)
- 衿は**喉のくぼみから指2本下**で合わせる。**胸の谷間は見えない**
- **衣紋(首の後ろ)はげんこつ1つ分**抜く。うなじが見えるのはここだけ
- 裾はくるぶし丈、おはしょりは腰にすっきり一段

### 帯と小物
- **兵児帯(へこおび)**を**文庫結び**で。柔らかい生地がふんわり広がる形。
  背中の結びが見える構図では必ず描く
- 帯は無地または細いストライプ。浴衣が大柄なので帯はシンプルに
- 帯飾りに小さなパール、または金の小鈴(作品のモチーフ)
- 巾着、赤い鼻緒の下駄

### 髪型
- **アップまたはハーフアップ**にまとめ、うなじを出す。普段の下ろし髪のままにしない
- 髪飾りはドライフラワー系＋既存の赤いリボン

### やってはいけないこと
- 胸元を開ける/谷間を見せる(着付けとして誤り。男性目線の記号)
- 左前(死装束になる)
- 帯を単なる黒い帯板として描く(結びが無いと浴衣に見えない)
- 髪を普段のまま下ろす
- 小花を全面に敷き詰めた古い柄行き

## 3. 祭りの装い(前夜祭の夜店通り / 記念撮影所)

- 赤と黒の市松模様の半被。下は黒の短パンと黒ニーソックス
- 腰に金の巾着と小さな鈴、赤い鼻緒の下駄
- 手に食べかけの林檎飴か綿あめ
- 表情は無邪気に楽しそう
- ※半被は羽織りものなので着付けの制約は浴衣ほど厳しくない

`sprites/mimi-festival-v1.png` として作成済み。

## 4. 私服(雨の休日 / カシムbond の倉庫街お茶会)

`sprites/mimi-casual-v1.png` として作成済み。
オフホワイトのゆったりニット＋くすんだ紺のロングスカート＋黒タイツと黒ショートブーツ。
首元に細い赤のリボンチョーカーだけ残して作品色を繋ぐ。赤い折り畳み傘、茶色の斜めがけカバン。
髪は下ろしたまま少し湿らせる。勤務中の作った笑顔ではない、素の穏やかな表情。

## 5. 正装(真エンディング「柿落とし、十五幕」)

`sprites/mimi-formal-v1.png` として作成済み。
深紅のロングテールコートに金の精緻な刺繍。中は黒のベストと白のジャボで首元まで詰まる。
黒のロングスカートに金の縁取り、白い手袋、肩に金の飾り紐とエポレット。
黒のヒールブーツ、手に金の指揮棒。髪を結い上げて赤いリボンを格式高く。
誇りと少しの緊張が混じった凛とした表情。
