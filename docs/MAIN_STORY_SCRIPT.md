# 第一部 この物語は何の話か

## ノリ(最重要)

**実況パワフルプロ野球のサクセスモード。** 熱血スポ根×ギャグの部活ノリで、
主役は毎回の大会とライバルと仲間。会社との対立は物語の背骨だが、画面の主役は
常に「次の試合」。書類や規定は笑いの小道具に留め、手続きドラマにしない。

- 毎大会に**顔と因縁のあるライバルチーム**を置く。再戦で盛り上がる。
- 仲間との練習・失敗・成長を、大会の前フリとして毎週積む。
- 強敵はちゃんと強く、勝利はちゃんと気持ちよく。負けても次の大会が燃える。
- 変な奴がいっぱい出る。変な奴は必ず大会で再登場する。

## 世界(正典の再確認)

ここは**物語が終わったあとの世界**である(裏付け: [MAIN_STORY_RESEARCH.md](MAIN_STORY_RESEARCH.md))。
一つのRPGの後日談ではない。**七つの世界、それぞれの終わった物語**から、人と物が
流れ着く集積地である。正典の裏設定([GAME_DESIGN.md](GAME_DESIGN.md) §2)——
**「クリア後の世界は物語が進まず、仲間と報酬だけが積み重なる」**。時間が止まった
やり込みの世界で、大会と収集と仲間集めだけが回り続けている。

裏ボスとは、ゲーム文法における**「最強なのに、誰も会いに来なかった存在」**である。
勇者が寄り道しなければ、戦われないまま本編が終わる。強さと出番が切り離された
孤独と滑稽——だからこの闘技場は、彼らに**初めて観客がつく場所**であり、
負けても終わらない(また明日戦える)戦いという救いである。

運営はアルデバラン社。同社の物語資産管理部は、**終わった物語を資産として所有し、
再演で収益化する**部署である(Q2。2周目の芯)。

ミミは物語を持たない普通の派遣バニーガールとして、この「物語を終えた規格外たち」
の真ん中に放り込まれる。**物語に選ばれなかった人が、物語を終えた人たちの
居場所を作る**——この一本が三周を貫き、真エンディング(柿落とし十五幕)は
「この闘技場での日々こそが、あの人たちの真エンドルートだった」で結ばれる。

## 1周目の背骨(あらすじ)

派遣バニーのミミは、闘技場の臨時接客に出た二日目、前オーナーの返却手続きの
事故で暫定オーナーになる。名義訂正を申請しつつ、疲れた体に「優勝賞品・温泉旅行」
が刺さって初心者大会に出たら、集めた知り合いが全員裏ボス級で圧勝してしまい、
チームランクが**最上級へ異常昇格**。「最上級在籍中の名義変更は不可」の規定で
訂正の道も塞がれ、**辞められない監督生活**が始まる。

最上級で揉まれる中盤、アマラに「全員、全力を封じたまま勝とうとしている」ことを
見抜かれる。うちの選手たちの**本来の領域**は、契約と長い自制で封印されている——
週13から、封印を安全に解くための特訓が始まる(週16初披露で半分だけ解けて盛大に
暴発→週20一斉解放→週26制御された全開、の三段払い。ゲームの解放機会
週12・20・25と噛み合わせる)。週14、名義訂正がついに受理可能になるが、ミミは
申請を自分で取り下げる。「この名義で、やりたいことができました」。

週20、所有者グランプリの朝——**世界の滅亡(四度目)が来る**。住人は慣れた手際で
避難を始め、ミミたちはライバル五人と共闘して、**滅亡を止めるドタバタの防衛戦**を
戦う。全員の封印を一斉に解いて、世界は救われる——が、闘技場は半壊、今季は消滅、
会社は「無認可の全力解放は契約違反」としてチームの緊急回収を始める。世界を救った
代償が、チームの解体。どん底。週22、四度目の復興が始まり、会社の火事場の回収は
選手全員の**本人同意欄の署名拒否**と「書類不備」で差し戻される。瓦礫から見つかった
設立趣意書——**「当場は、物語を終えた者たちが、続きを生きるための場所である」**——を
合言葉に闘技場は再建され、復興選手権が開かれる。

週24の準決勝(カシム・ベル)で解放が初めて試合の中で美しく決まり、週26、
空の王者シャハルとの決勝。
勝っても敗れても、滅亡から三週間でここへ戻った事実は揺らがない。エピローグで
ミミは手帳の「暫定」の上に「監督」と書き足し、スタッフロール(配役は全員「主演」)が
流れ、ポストクレジットで会社の収録機材が見つかる。ラベルは「新企画: 世界滅亡ショー
(再演)・収録素材」。——滅亡は、収録されていた? 2周目の扉。

# 第一部補 裏ボスというイレギュラー(ゲーム文法の帰属先)

**裏ボスの文法は、街の文化ではない。** 街はクリア後世界のふつうの興行街であり、
住人は普通に働き、普通に賭け、普通に観戦する。ゲーム文法の属性はすべて、
**この設定に導かれて流れ着いたイレギュラー——裏ボスたち個人**に帰属する。
実在作の固有名は作中に出さない。文法だけを借りる。

| ゲーム文法 | 実例(執筆時の参照) | 帰属先: 裏ボスたち個人の属性 |
|---|---|---|
| 会いに行く側に条件がある | 隠しダンジョン最深部、全踏破、宝箱、眠り、徘徊 | 彼らは各自の世界で「条件を満たした者しか辿り着けない場所」に居た。誰も条件を満たさないまま物語が終わり、**行き場を失った者だけが、この街へ導かれる**。イレギュラーの入場条件 |
| 撃破ターン数が勲章になる | エスターク15ターン以内=仲間化、ダークドレアム20ターン以内=特別エンディング | 彼ら個々の「伝説の語られ方」。挑まれた記録を本人だけが覚えている(挑戦者は来なかった、または一組だけ来た、等)。街の賭けの風習にはしない |
| 報酬は願い・称号・再戦解放 | ダークドレアムの願い | 彼ら個人が「倒した者へ与えるはずだった何か」を、渡せないまま持っている。個別ストーリーの領分に近い素材。メインでは深掘りしない |
| 倒しても消えず、何度でも戦える | 再戦可能の様式 | 彼らの存在の性質。だから闘技場は彼らの受け皿になれる——**負けても終わらない戦い**は、この場が彼らに与える救い |
| 強さと出番が切り離されている | 多くのプレイヤーは裏ボスに会わずクリアする | 「最強なのに誰も会いに来なかった」の哀感。彼らがイレギュラーである理由の芯。闘技場は初めて観客がつく場所 |

メインストーリーがこの表から使うのは下二段(場の機能と哀感)まで。上三段は
各キャラの個別ストーリーが本人の形で扱う素材であり、メインは先食いしない。

# 第三部 2周目「更新後の勤務週」全26週の週割り

問い: **「再演」の仕組みは、新作で打ち倒せるか?**(Q2の画面化)

**この周の型(2026-08-15 ユーザー決定)**: 3周目への引きに留めない。**最も盛り上がる
王道の組織打倒物語**にする。悪しき裏側の仕組みが見えてきて、**優勝することで
ルールを一つずつ壊し**、支配ではなく自由と信念の勝利を手にする栄光の物語。
会社の「裏側」は同情の余地を残しつつも、現在の運用は明確に**悪**として描く
(人を封筒で消し、資産として縛り、滅亡すら商品にする)。

原理: 同じ暦の二年目。「去年と同じ/違う」の差分が不思議さの源泉(幕一)。
覚えている者(ミミ・仲間・物語を終えた者たち)と覚えていない者(街の大半・会社)の
線引きが世界法則。幕二からは打倒の坂へ転じる。

## 壊すルールの台帳(優勝のたび、一条ずつ赤線で消す)
