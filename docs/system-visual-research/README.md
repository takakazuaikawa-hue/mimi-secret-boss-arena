# システム画面のビジュアル基準

## マスター

既存の週行動画面を全システム画面の品質・情報設計・画面文法の基準にする。
週画面そのものを別のダッシュボード風デザインへ変更しない。

共通要素は次のとおり。

- 背景絵を画面全体の舞台として使う
- 操作領域は濃紺の半透明パネルにまとめる
- 白い帯は短い状況表示に限定する
- コーラルを決定、ティールを選択・進行、金を記録・格に使う
- 角丸カードではなく、角を落としたチケット形状を使う
- 明朝体を見出し、ゴシック体を操作・数値に使う
- 重要な決定は下部の専用コマンド帯へ置く
- 800×450の論理画面内で、ページ全体を縦スクロールさせない

## 管理画面

[management-week-standard-v1.png](./management-week-standard-v1.png) は構図の基準。
画像内の固有名詞・数値・装備名は実装データではなく、レイアウト参照に限る。

- 左: 所属選手の選択レール
- 中央: 選択中の人物を大きく見せる舞台
- 右: 育成と装備の操作
- 下: 保存状態・準備状況・次週への決定

## 記録室

週画面と同じ背景絵＋濃紺パネルを使い、白い管理台帳風へ戻さない。
記憶画廊では一枚絵を主役にし、未解放枠も同じグリッド上で明確に区別する。

## 自動監査

`scripts/system-commercial-qa.mjs` はゲーム本体のストア処理から再現可能な週・管理状態を作り、800×450でタイトル、週画面、管理画面、記録室、記憶画廊を撮影する。横・縦の文書はみ出し、コンソールエラー、主要領域の実寸を同時に確認する。
