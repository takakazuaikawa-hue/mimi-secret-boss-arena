# うしろ人物物語監査

## 役割

うしろはドタバタコメディ主調である。夜を食べるものの「気配だけの親密さ」と
重ねず、いたずら、観察、集合写真、座席数、同時多発する背後を笑いの軸にする。
感情の到達点は、発見されることではなく、普段は他人を観察するミミがうしろから
観察され、少し落ち着かなくなる立場の反転に置く。
