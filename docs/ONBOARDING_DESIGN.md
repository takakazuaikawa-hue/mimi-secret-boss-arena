# 導入・初回学習設計

更新日: 2026-07-26

## 導入の完了条件

導入はプロローグを読み終えた時点では終わらない。プレイヤーが次の一巡を
自力で予測できた時点を完了とする。

1. ミミが自分の契約原本を調べたい理由を知る。
2. 原本へ近づくには、最初の出場候補を登録する必要があると知る。
3. 一週間の予定を一つ選ぶ。
4. 選んだ予定の延長でギドノゼアースと出会い、二択を決める。
5. 選手登録、契約記録室の仮承認、育成Pの獲得を結果として見る。
6. 最初の2Pを使い、第2週の予定選択へ戻る。

この一巡で「週の予定 → 人物との出来事 → 結果 → 育成 → 次週」という
通常ループを、説明一覧ではなく操作と結果で覚える。

## 採用原則

### Attraction / Goal / Effectiveness

最初に兎耳、カジノ、記憶にない契約という異常へ引き付ける。次に
「契約原本を見る」という短期目標を置く。最初の選手登録で閲覧権限が
変化し、自分の行動が有効だったことを画面で返す。

出典:
[GDC 2024: Start Right, Start Fun](https://www.gdcvault.com/play/1034824/Start-Right-Start-Fun-Unveiling)

### Prime / Teach / Observe

プロローグでは「毎週一つ選ぶ」「ミミは戦わない」「人へ声をかける」を
準備する。初週は予定選択と人物二択を実行させる。結果画面と初回育成で
理解を確認し、以後の画面では通常情報を開示する。

出典:
[GDC 2014: Prime, Teach, Observe](https://www.gdcvault.com/play/1020512/Prime-Teach-Observe-Tutorializing-Innovative)

### 物語とシステムを同時に始める

設定説明のあとでゲームを始めるのではなく、契約原本を調べる行為そのものを
スカウト、登録、育成の入口にする。固有名詞は、行動か結果に関係する時だけ
導入する。

出典:
[GDC 2010: I Don't Want to Know](https://gdcvault.com/play/1013829/I-Don-t-Want-to)

### 小さな環境で、目的に沿って覚える

初週は日程表、ルート規則、チーム数値を隠す。最初の登録後も、全能力、
編成、装備、ショップを同時には出さず、信頼、所有、共有2Pだけを扱う。
第2週から通常画面へ移行する。

出典:
[James Paul Gee: Learning by Design](https://media.gdcvault.com/gdc04/slides/learning_by_design.pdf)

### 認知負荷を制限する

初回の各画面で主判断は一つだけにする。意味のない再説明、同じ内容の
言い換え、将来使う数値の先出しを避ける。

出典:
[GDC 2016: The Gamer's Brain](https://media.gdcvault.com/gdc2016/Presentations/Hodent_Celia_TheGamersBrain.pdf)

## 段階開示

| 段階 | 見せるもの | まだ見せないもの |
| --- | --- | --- |
| プロローグ | ミミ、契約原本、最初の登録 | 能力値、試合規則、全26週 |
| 初週 | 4つの予定と物語上の意味 | 確率、資金効率、ルート規則 |
| 初遭遇 | 一人の人物、二つの応答 | チーム全員、ショップ |
| 結果 | 加入、仮権限、変化した数値 | 次の最適化 |
| 初回育成 | 信頼、所有、共有2Pの二択 | 6能力の自由配分、装備 |
| 第2週以降 | 通常の予測、日程、編成、育成 | なし |

## 回帰条件

- 初回プロローグは27送り以内、周回用あらすじは6送り以内。
- どの初週行動を選んでも、ギドノゼアースとの出会いの冒頭がその行動を受ける。
- 初回加入結果に「所属選手」と「契約記録室の仮承認」を同時表示する。
- 初回管理画面は一人、二つの関係値、二つの育成候補だけを表示する。
- 第2週へ進むと通常の週行動画面へ戻り、その後は特別画面を繰り返さない。
- PCとモバイルで、主判断、次の遷移、文章が画面外へ欠けない。
