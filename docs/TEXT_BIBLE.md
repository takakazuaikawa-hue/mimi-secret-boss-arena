# テキスト制作基準

更新日: 2026-07-25

## 目的

本作の文章は、設定を説明するためではなく、プレイヤーに「その週、その場所で、ミミと誰かの間に何かが起きた」と感じてもらうために書く。

『ときめきメモリアル Girl's Side』の本文を模倣しない。日常の用事、季節や時間、少しずつ変わる距離、選択後の反応という体験設計を学び、本作固有の人物と世界で新しく書く。

## 表示文の視点

- 通常場面はミミの一人称固定。ミミがその時点で知らない事実、見ていない動作、他人の内心は書かない。
- 地の文相当も、ミミが今見たもの、聞いた音、身体感覚、連想として書く。「ミミは」と外から説明しない。
- 内心には話者名を表示しない。声に出した台詞だけに「ミミ」の名前札を出す。
- 一回の送りは、一つの話題についてつながった一〜三文を基本にする。短さより、主語・目的語・因果が自然な日本語として完結することを優先する。
- 台詞は直前の発言に答える。質問を無視して別の設定を話し始めない。話題が変わるときは、視線、手渡された物、着信など、画面内の出来事を橋にする。
- 場面の最初の三表示までに「どこにいるか」「直前まで何をしていたか」「今は何をしようとしているか」が分かるようにする。
- 固有名詞や制度名は、意味の分からない音として置き去りにしない。ミミが聞き返す、相手が具体例を出す、その場で実物を見る、のいずれかで受け止める。
- 名詞で切る断片文や翻訳調の省略を、テンポの代わりに使わない。声に出して、日本語話者同士の受け答えに聞こえるか確認する。
- 背景に見える室内を列挙しない。立ち絵で分かる表情を「笑った」と重ねず、ミミがどう受け取ったかを書く。
- 主人公の通常立ち絵は出さない。ミミ自身が映るのは、記憶に残る一枚絵として構図を見せたい瞬間だけ。

制作時の指示は本文へ書かず、シナリオデータの `background`、`sprite`、`still`、`effect` に分離する。

## 調査から採用する技法

### 日記・随筆

- [夏目漱石『硝子戸の中』](https://www.aozora.gr.jp/cards/000148/files/760_14940.html)
  - 視点人物が実際に見られる狭い範囲から始める。
  - 物の形、身体の位置、小さな動作を置いてから考えへ移る。
  - 大事件そのものより、事件を見た人の記憶や引っかかりを書く。
- [今日のダーリン](https://www.1101.com/darling_column/yesterday.html)
  - 日常の小さな事実から、その日に浮かんだ感情や考えへ進む。
  - 最初から結論を掲げず、書き手が気づいていく順序を残す。
- [ダカフェ日記](https://dacafe.cc/grape2)
  - 家や近所の反復が、人物と時間の蓄積を作る。
  - 特別な日だけでなく、同じ場所の小さな違いを記録する。
- [文芸社「写真に勝つ情景描写」](https://www.bungeisha.co.jp/publishing/kakitai/article_195_7.jsp)
  - 景色を客観説明で終わらせず、人の心に作用した部分を選ぶ。
- [榎本メソッド「伝わる風景・情景描写」](https://enomotomethod.jp/column/landscape_scene/)
  - 視覚だけに偏らず、音、匂い、温度、触感を必要な分だけ使う。
  - 架空の景色ほど、読者が知っている感覚を足場にする。
- [佐賀県教育センター「心の機微を日記に書こう」](https://www.saga-ed.jp/kenkyu/kenkyu_chousa/h30/01_syo_chu_kakukyouka/05_tyu_kokugo/documents/2_4_2_shidouan1.pdf)
  - 心情は、人物の言動と情景に根拠を持たせる。

### 恋愛・生活シミュレーション

- [『ときめきメモリアル Girl's Side 3rd Story』公式座談会](https://www.konami.com/games/girls_side/3rd_Story/zadankai/index.html)
  - 重い題材も、突飛な説明ではなく普通の生活の中で起こす。
  - 通常会話は自然な流れを守り、必要な情報を少量ずつ混ぜる。
  - 外から見える態度と本人の内面には、意図した差を作る。
- [『ときめきメモリアル Girl's Side 2nd Season』公式座談会](https://www.konami.com/games/girls_side/talks/)
  - 用事の本番だけでなく、帰り道や待ち時間に感情が動く余地がある。
- [『リフレインラブ』ディレクターインタビュー](https://www.gamespark.jp/article/2026/04/26/165712.html)
  - 人物の人生を全部説明せず、日常で見えた断片を積み、間をプレイヤーに結んでもらう。
- [「ノベルゲームのシナリオ作成技法」書評](https://www.jstage.jst.go.jp/article/digraj/2/1/2_172/_pdf/-char/ja)
  - CG、台詞、地の文、音、演出は同じ情報を重ねず、役割を分ける。
  - 主人公が今見ているものと身体反応を伝える一人称的な実況は、プレイヤーとの距離を縮める。
- [『ときめきメモリアル Girl's Side 4th Heart』公式システム](https://www.konami.com/games/girls_side/4th_Heart/system.html)
  - 背景、キャラクターの動きと表情、短い会話表示を一つの場面として運用する。
  - 会話ウィンドウを隠してイベント絵を見られる操作を備える。
- [ひつじぐも「乙女ゲームシナリオ制作」](https://hitsujigumo.co.jp/column007/)
  - 台詞、表示される本文、背景・立ち絵・表情などの演出指定を分離する。
  - 特別な場面には一枚絵、通常会話には背景と立ち絵を使い分ける。
- [AMG「ゲームシナリオの書き方」](https://www.amgakuin.co.jp/contents/novels/column/scenario-writer/game-scenario/)
  - 背景と立ち絵が場所・人物・表情を伝えるため、同じ情報を文章で詳述しない。
  - 一画面の行数と文字数を決め、選択後の反応を設計する。

## 画面演出の文法

1. 場所は専用背景で見せる。文字ラベルは初見確認用の小表示に留める。
2. 相手は右寄りの立ち絵で見せる。話者が変わっても、場面にいる限り消さない。
3. 目線、緊張、安堵、力の発露は表情・形態差分で先に見せ、本文はミミ側の反応を担う。
4. 一枚絵は常時背景にしない。発見、力の露出、解放など、その周回で覚えてほしい一表示に使う。
5. メッセージ窓は下部固定。内心には名前札を付けず、会話だけ名前札を付ける。
6. メッセージを隠す操作と、既読場面を選択肢まで送る操作を常備する。
7. 選択肢は本文を読み終えたあとに出し、背景と最後の立ち絵を残して判断させる。

## 本作の一場面

各イベントは、次の順序を基本にする。面白さを損なう場合は順序を崩してよいが、要素そのものを省かない。

1. **足場**
   - 時刻、光、音、匂い、温度のうち二つまで。
   - ミミが直前までしていた具体的な仕事。
2. **その日の用事**
   - パフェを運ぶ、休憩を取る、契約書を読むなど、一文で言える用事。
3. **小さな異常**
   - 最初は目の前の物として示す。世界設定の名前で説明しない。
4. **身体の反応**
   - 恐怖、安心、寂しさと書く前に、呼吸、手、視線、姿勢、声の変化を書く。
5. **会話の往復**
   - 質問には答える。話題が飛ぶときは、動作か新しい出来事で橋を架ける。
6. **選択**
   - 正解当てではなく、ミミが相手をどう扱うかを選ぶ。
7. **余韻**
   - 選択直後の相手の反応と、場面に残った物を一つ書く。

## ときめきの代わりに積むもの

本作の中心は恋愛ではない。接近の手応えは、次の変化で作る。

- 名前や勤務時間を覚える。
- 前回と同じ場所に、違う理由で座る。
- 相手が自分の都合だけでなく、ミミの都合を数え始める。
- 命令でできたことを、頼みや約束で行うようになる。
- 相手の強さではなく、弱さや生活上の癖を知る。
- 解放後に、契約なしで同じ場所へ戻ってくる。

## 情景と感情

- 五感を全部入れない。ミミの注意が向いた二、三点だけを選ぶ。
- 感情ラベルは、動作と情景だけでは誤読される場合に限って使う。
- 背景画像に見えるものは列挙しない。画像では伝わらない温度、音、時間、意味を書く。
- 比喩は一段落に一つまで。意味が取れない比喩は削る。
- 「何か」「それ」「あれ」が二文続いたら、具体名へ戻す。
- 抽象語を発した人物は、同じ場面内で具体的な行動か結果を示す。

## 人物の声

### ミミ

- 接客業で身についた観察と、働く人の具体的な愚痴を持つ。
- 驚いても状況確認をする。理解できないことを分かったふりにしない。
- 笑いはメタ発言ではなく、巨大な異常を勤務上の問題として受け止めるところから出す。
- 感情は素直だが、すぐに美しい言葉へまとめない。

### ギドノゼアース

- 短く、文字どおりに答える。自分の格を説明しない。
- 三百年と三分を同じ落ち着きで数える。
- パフェへの執着は冗談ではなく本気。その本気が結果としておかしい。
- 信頼は優しい台詞より、待つ、温度を保つ、鍵を返すといった行動で示す。

## 反復する小道具

- 窓際の予約席: 偶然の同席から、契約なしで選ぶ同席へ変わる。
- 欠けたマグカップ: 遅れた休憩と、相手がミミの時間を数え始めた証拠。
- パフェの伝票: 契約書より古く、二人が最初に同じ卓へついた記録。
- 黒い星: 脅威の印から、感情の小さな動きを読む目印へ変わる。
- 水平線: 力が漏れたときは揺れ、解放後の最後には揺れない。

## 禁止する逃げ

- 「裏ボス」「攻略対象」「ルート」「プレイヤー」など、ゲーム外から自分を説明する台詞。
- 設定資料を読んでいるような相互説明。
- 全員が抽象的で詩的な口調になること。
- 三点リーダと沈黙だけで感情を済ませること。
- 選択結果を数値だけで終えること。
- 既存作品の台詞、固有の言い回し、場面構成の直接的な模倣。

## 原稿監査

初稿後、次を声に出して確認する。

1. 初見の人が、最初の三表示で場所と用事を言えるか。
2. 各発言が、直前の発言か目の前の出来事へつながっているか。
3. 感情を読み取る根拠が、動作か情景にあるか。
4. 背景画像を消しても、温度と時間帯が伝わるか。
5. 名前を隠しても、ミミと相手の台詞を区別できるか。
6. 選択前に態度の違いが分かり、選択後に反応が返るか。
7. 前のイベントから変わった物、呼び方、習慣が一つあるか。
8. 設定を半分削っても、その日の出来事として読めるか。
9. 場面の直前、現在の用事、新しく分かったこと、次にすることを一文ずつ説明できるか。
10. 問いかけの直後に、その問いへの返答または返答できない理由があるか。
11. 一文だけ切り出して格好よく見せるために、会話全体の意味を壊していないか。

合否は文字数で決めない。意味が通り、感情の根拠があり、次の再会を見たくなることを合格条件にする。
