# メインストーリーの課題(2026-08-11 プレイヤー指摘)

1周目26週のメインを実際に読んだうえでの指摘。**未着手**。着手前にこの4点を設計へ反映する。

## 1. 台本のようで、ノベルとして機能していない

各話が「見せ場の説明」と「短い掛け合い」の連なりになっており、地の文が場面を運んでいない。
一文ずつが状況報告で、視点・呼吸・間が作られていないため、読み物としての手応えが出ない。

原因: 21話を「毎回違う見せ場」という単位で発注したため、出来事の一覧としては成立したが、
語りの連続性(ミミの目線がどこにあり、何を感じ、何を考えたか)が設計に入っていなかった。

## 2. 「ミミがこの世界を知っていく」という主題に合っていない

世界の断片は毎週出るが、ミミがそれをどう受け取り、何を学び、どう変わったかが積み上がらない。
知識が増えるだけで、理解が深まる筋になっていない。第1週と第26週でミミの何が違うのかが言えない。

## 3. 大会出場やラストへ向かう意味を説明できていない

四週ごとの大会が「その週の出来事」として消費され、次の大会への渇望や、最終戦へ向かう理由が育たない。
プレイヤーが「この大会に出たい」「この先を見たい」と思う動機づけが、物語側に無い。

## 4. 既存イベントとの整合性が取れていない

- **第5週(温泉)**: 既存の温泉旅行イベントがある週へ、温泉を題材にしたメインを重ねてしまい、
  **温泉の話が二本続けて再生された**(プレイヤー報告)。応急処置として第5週のメインを外し、
  その週は既存の温泉イベントが物語を担うようにした(2026-08-11)。
  加えて `main.s1.w05` は温泉へ行った前提で書かれているが、温泉旅行の発生条件は
  「初心者大会で優勝」(`engine.ts` の `opening-cup:champion` 判定)。負けた周回では成立しない。
  このファイルは未使用のまま残してあり、書き直して別の週へ回す。
- 同様に、勝敗・加入状況・解放状況で分岐する既存イベントとの前後関係を、全26週で検査していない。
  解放週(第12・20・25週)はメイン+週イベント+解放場面が同じ週に重なる可能性があり、分量の検査が要る。

## 5. 情景が浮かばない

出来事は書いてあるが、読者の頭に画が立たない。画像で補うにも限度がある。

原因: 全文が「私が◯◯すると、△△した」という行為の報告文で構成されており、
光・音・匂い・温度・距離・手触りが一切書かれていない。場面の立ち上げ(その場所が
どこで、何が見えていて、どんな空気か)を省いたまま事件だけを進めている。

これは「地の文で風景を列挙する説明は禁止」という執筆規約を、私が
「描写を書かない」と取り違えて発注したことによる過剰補正。正しくは
**ミミの知覚を通した描写**であり、描写そのものを削ることではない。

## 6. 先を読ませようとしていない

各話が過不足なく閉じてしまい、次を読む理由が残らない。連続ドラマとしての引きがない。
未解決を持ち越す、疑問を植える、次週の予兆を置く、といった仕掛けが設計に入っていない。

## 7. 読者への配慮がない

七つの世界の名前は出るが、それがどんな場所なのか読者には分からないまま話が進む。
新しい語・場所・仕組みを、読者が気になる形で見せる/触れさせる手当てがない。
初見の読者が「それは何?」と思う箇所に、答えも手掛かりも置かれていない。

## 8. 連続ドラマの感覚がない

前話の出来事が今話に効かない。繰り返し出る人物・小道具・場所の積み重ねがない。
シーズンを貫く一つの問いがなく、二十六話が並列に並んでいるだけになっている。

## 書き直すときの型(案)

一話の中に、次の四つを必ず置く。

1. **立ち上げ**: その場所を、ミミの知覚(見えるもの・音・匂い・温度)で二、三文。
2. **事件**: ミミが動き、世界が過剰に応える。ここは現行の強み。
3. **反応**: 出来事をミミがどう受け取ったか。理解が一段進んだ形跡を残す。
4. **引き**: 未解決をひとつ残す。次週の入口になる。

加えて、シーズンを貫く装置を用意する。

- 前話の結果が今話の冒頭に顔を出す(小道具・人物・噂のいずれか)。
- 毎話に、読者が「気になる」ものを一つ置く(答えは次話以降)。
- 大会が近づくにつれ、街の温度が上がっていくことが文章で分かる。

## 着手するときの順序(案)

1. 26週を貫く一本の筋を先に決める(ミミの理解の段階と、大会への動機がどう育つか)。
2. その筋に沿って各話の役割を割り当て直す。見せ場は筋に従属させる。
3. 既存イベント(温泉・大会・移譲・解放週)との前後条件を表にして、矛盾しない週へ配置する。
4. **まず一話だけ書き直し、文体の基準を確認してもらう**。合意できてから残りへ広げる。
   (今回は基準を確かめずに二十一話を一度に発注したため、全話に同じ弱点が乗った)
5. 文体をノベルとして書き直す。地の文で運び、掛け合いは要所に置く。
